案情介绍

基瓦利纳位于阿拉斯加西北海岸的屏障礁上，居民以因纽皮亚特原住民为主，长期依赖北极海冰抵御冬季风暴和海浪侵蚀。申请人主张，22家被告公司（石油、能源及公用事业巨头）的大量温室气体排放加剧全球变暖，导致北极海冰形成延迟、消融提前且厚度变薄，失去保护的基瓦利纳遭遇严重海岸侵蚀，村庄濒临毁灭，需整体搬迁。2008年，申请人向美国加利福尼亚州北区联邦地区法院提起诉讼，依据联邦普通法"公共妨害"理论，要求被告赔偿搬迁及相关损失。地区法院以"政治问题不可裁判"和"缺乏诉讼资格"为由驳回起诉，申请人上诉至美国第九巡回上诉法院。2012年9月21日，第九巡回上诉法院作出终审判决。

判决结果

1.美国加利福尼亚州北区联邦地区法院：驳回起诉，理由是：(1) 案件涉及温室气体排放上限、成本分担等核心政策问题，属立法与行政分支权限，司法缺乏裁判标准，构成 "政治问题"；(2) 申请人无法证明损害与被告排放行为存在直接因果关系，不符合宪法第三条诉讼资格要求；
2. 美国第九巡回上诉法院：维持地区法院判决，核心裁判理由为：(1)《清洁空气法》（Clean Air Act）及美国环境保护署（EPA）的监管权限已取代联邦普通法公共妨害索赔，国会已通过立法建立温室气体排放的综合监管体系，无需司法通过普通法创设救济；(2) 无需再审查诉讼资格问题，仅依据"法律取代"原则即可维持驳回裁定。

发起路径

1.起诉：2008年，申请人向加利福尼亚州北区联邦地区法院提起诉讼（application），依据联邦普通法公共妨害理论，主张被告温室气体排放导致村庄侵蚀，请求判令赔偿；
2.被告反对：Respondents提交答辩意见（observe opinion），辩称案件属政治问题、申请人缺乏诉讼资格、《清洁空气法》已取代普通法索赔，请求驳回起诉；
3. 法院审理：地区法院驳回起诉；申请人上诉后，第九巡回上诉法院审查法律适用问题，最终维持驳回裁定。

回应路径

1.法律取代抗辩：主张《清洁空气法》已建立温室气体排放的综合监管体系，国会授权EPA负责排放管控，涵盖标准制定、执行与救济机制，联邦普通法公共妨害索赔已被立法取代；
2. 政治问题抗辩：声称案件需确定温室气体排放上限、成本分担等核心政策，属立法与行政分支专属权限，司法缺乏明确裁判标准，不应介入；
3. 诉讼资格抗辩：辩称申请人无法证明损害与被告排放存在"直接且可追溯"的因果关系，气候变化是全球多主体排放导致的结果，无法单一归因于特定被告；
4. 因果关系抗辩：强调温室气体在大气中快速混合，排放来源多元且持续数百年，申请人无法区分被告排放与其他排放的具体影响，因果链过于间接；
5. 行业联合抗辩：联合能源行业协会、商会等第三方介入诉讼，主张司法裁判将破坏能源行业稳定，影响经济发展与能源安全。

因果启示

1.反制"普通法索赔"：若面临类似环境侵权索赔，可援引专门立法的监管体系，主张立法已取代普通法救济，司法不应创设额外义务；
2. 反制"因果关系主张"：在气候变化相关诉讼中，强调排放来源的多元性、大气混合的不可区分性，举证因果链的间接性与不确定性，反驳单一归因主张；
3. 强化监管合规举证：提前留存符合环境法规与排放标准的证据，凸显已履行法定监管义务，主张责任认定应限于立法明确规定的范围；
4. 依托行业与政策协同：联合行业协会、强调政策导向，主张司法裁判应尊重立法与行政分支的监管权限，避免过度干预经济与能源政策；
5. 前置风险防范：在高环境风险区域运营时，提前开展气候影响评估，与当地社区（尤其是原住民）建立沟通机制，通过生态补偿、公益投入等方式降低诉讼风险。
