原告

佩德罗·瓦斯奎兹·佩尔多莫(Pedro Vasquez Perdomo)等（代表“无证逮捕集体”及相关移民权利组织，如LAWCN, UFW, CHIRLA）

被告

克里斯蒂·诺姆(Kristi Noem)等相关政府官员

案情介绍

原告以集体诉讼形式提起诉讼，指控被告在移民执法过程中存在系统性的宪法违规行为。核心争议集中在：执法机构实施“无证逮捕”缺乏合理怀疑 (Probable Cause)的证据支持，违反了美国宪法第四修正案关于禁止不合理搜查与扣押的规定，同时违反了第五修正案关于正当程序的要求以及联邦关于逮捕标准的法规。原告要求通过司法裁定纠正此类行政执法行为，并对受害集体进行救济。

判决结果

该案目前处于诉讼程序阶段。法院在2025年7月对案件的相关动议作出裁定（如拒绝暂缓执行动议等），案件目前仍在审理中。法院通过一系列程序性裁决，确认了案件在联邦法院进行实质审查的管辖权，案件进入证据开示与实质辩论阶段。

发起路径

1.集体诉讼路径 (Class Action)：原告将分散的移民个体抗辩整合为“无证逮捕集体”，利用集体诉讼的规模效应，直接挑战政府行政执法规则的宪法合规性。
2.宪法诉由嵌入：通过将具体的执法行为定性为对第四、第五修正案的系统性侵犯，将行政违规争议上升至宪法保护高度，增加了行政诉讼的胜诉筹码。

回应路径

1.职权合规性抗辩：被告方（政府官员）主张其执法行为符合相关行政法规与国家安全管理权限，试图证明逮捕标准具备法律依据。
2.程序性阻滞：被告通过动议等方式尝试暂缓执行相关司法披露要求，试图在审理周期内压缩原告获取证据的空间。

因果启示

1.共性启示：涉及跨国移民与人权保障的集体诉讼，通常利用高强度的宪法修正案作为突破口，将个案纠纷转化为系统性的行政合规诉讼。此类案件不仅是权利救济，更是对行政执行权边界的司法划界。
2.个性启示：该案展示了法院在处理移民执法争议时，对行政强制措施的“合理根据”(Probable Cause) 要求极为严格。若缺乏法律明文授权的证据链，法院倾向于通过诉讼程序对行政权力进行约束。
3.中国涉外法治指引：我国出海企业及项目在面对境外此类移民或劳工执法争议时，应高度关注对方提起的集体诉讼策略。在涉及我方海外项目员工权益时，应通过专业的宪法与行政法合规审计，确保企业与政府的合作完全符合当地宪法程序，防止被作为集体诉讼的攻击对象。同时，务必严格做好企业内部涉及员工个人敏感数据与合规信息的分类保护，阻断此类集体诉讼中常见的“证据大范围调取”风险。
