原告

被告

德国巴登 - 符腾堡州政府

案情介绍

德国巴登-符腾堡州公职招录规则设置地域、国籍限制，阻碍欧盟境内劳动者跨境应聘州级公职。原告沙伊布尔主张该国内规则违反《欧盟运行条约》劳动者自由流动条款。德国受理法院存在法律分歧，向欧盟法院提交初步裁决请求，请求界定成员国公职岗位是否可以设置国籍、地域歧视门槛，区分行使主权核心公职与普通行政岗位的法律适用标准。

判决结果

1.纯粹行使国家主权核心公职可豁免欧盟劳动者自由流动规则；
2.普通州行政类公职不得设置国籍、地域歧视限制；
3. 巴登-符腾堡州不加区分统一设置招录门槛的国内法部分违反欧盟基础条约，成员国需修改相关用工规则。

发起路径

原告采取 “国内起诉 + 欧盟初步裁决” 双层战略诉讼：以个人就业受损提起国内诉讼，不局限个人赔偿诉求，主动引导法院提交欧盟初步裁决；通过个案推动形成统一判例，约束全德各州公职招录制度，借助欧盟法实现系统性平等就业变革。

回应路径

被告州政府分层抗辩：以成员国主权权力为核心论据，主张全部州级公职均有权设置国籍地域限制；要求法院宽泛赋予成员国立法自由裁量权，限制本案判例适用范围，避免各州招录规则统一调整，弱化判决对德国公权力用工体系冲击。

因果启示

1.私人劳动者可借助欧盟初步裁决程序开展战略性诉讼，以个案推动区域性体系法律修改；
2. 仅笼统主张主权、不区分岗位类型的应诉抗辩效力薄弱，法院会细化岗位边界划分；
3. 行政主体宽泛式主权抗辩无法完全规避欧盟平等就业义务，战略应诉需分层区分岗位进行论证。
