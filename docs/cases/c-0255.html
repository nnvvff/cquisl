案情介绍

9・11后美国设立CIA海外秘密黑监狱，实施非常规引渡（Rendition）、高强度酷刑审讯。纳什被指控策划科尔号军舰、林堡油轮爆炸，2002年10月在阿联酋被捕，经多国秘密中转，先后在泰国、波兰黑监狱遭受水刑、长时间悬吊、睡眠剥夺等酷刑。2004年4月12日，CIA私人引渡航班N85VM将纳什运至罗马尼亚布加勒斯特代号“Bright Light”（Detention Site Black）秘密监狱，直至2005年11月秘密转移出境。罗马尼亚情报、民航部门全程配合CIA，提供机场中转、秘密羁押场地，知情却未干预酷刑与非法单独监禁；纳什在此长期隔离、心理摧残，出现重度创伤后应激障碍。2005年华盛顿邮报曝光东欧黑监狱，罗马尼亚关闭该秘密设施。纳什后被移送关塔那摩军事委员会受审。

2012年5月纳什律师向罗马尼亚总检察院提交刑事举报，指控罗马尼亚当局协助美国实施酷刑、非法剥夺自由，要求立案调查引渡航班、秘密羁押、官员共谋行为。罗检方启动调查，但以航班档案过期、美方拒绝司法协助、涉密为由长期搁置，多年无嫌疑人起诉、无追责措施，国内救济完全失效。

纳什通过OSJI代理，依据《欧洲人权公约》第3（酷刑）、5（人身自由）、8（私生活）、13条（有效救济）向欧洲人权法院提交跨国人权申诉，主张罗马尼亚作为缔约国，明知CIA将实施酷刑仍提供场地、航空中转协助，构成国家共犯，国内无有效追责途径，侵犯其公约权利。

法院书面质证阶段（2013–2016）欧洲人权法院向罗马尼亚政府送达申诉副本；罗政府全盘否认境内存在CIA黑监狱，辩称航班仅普通过境、当局不知情，提交参议院调查报告、机场档案抗辩；申诉方提交美国参议院酷刑报告、迪克・马蒂欧洲议会调查、航班数据、专家证词、纳什庭审自述、心理鉴定报告等海量证据；大赦国际、国际法学家委员会、媒体联盟作为法庭之友提交书面意见。

2016年6月28日法院召开专门事实调查听证会，传唤马蒂、航班情报专家、酷刑调查专家当庭作证，完整还原引渡航线、黑监狱运营模式；6月29日公开口头辩论，双方围绕罗马尼亚国家责任、酷刑共犯、国内救济是否充分展开辩论。

2018年5月31欧洲人权法院作出实体判决，认定罗马尼亚违反公约多项条款；罗马尼亚未申请大法庭复审，2018年10月8日判决正式终局生效。

判决结果

实体侵权认定（核心结论）（1）违反《欧洲人权公约》第3条禁止酷刑：罗马尼亚明知纳什会遭受酷刑仍提供中转与秘密羁押场地，构成协助酷刑，国家承担国际法共犯责任；（2）违反第5条人身自由权：默许无司法授权、无限期单独秘密监禁，无会见律师、家属渠道；（3）违反第13条有效救济权：国内刑事调查长期搁置，无独立、快速追责机制，不存在公约要求有效国内救济；

救济判令 判令罗马尼亚向纳什支付精神损害赔偿金，同时要求罗马尼亚修改国内航空、情报监管立法，建立境外秘密引渡过境审查机制，定期向欧洲人权委员会提交整改报告；

本案成为欧洲人权法院首个明确“缔约国协助境外酷刑需承担公约责任”标杆判决，约束全部46个欧洲委员会成员国，大幅限制各国情报机关与第三国开展秘密非常规引渡合作。

发起路径

1.前置证据长期固化战略。纳什及其代理人权机构耗时数年整合证据：美国参议院6700页酷刑调查报告、欧洲议会马蒂报告、私人引渡航班完整航线记录、机场票据、多名酷刑受害者证词、心理创伤鉴定、CIA内部解密电报、罗马尼亚参议院涉密附件，形成完整证据链，弥补跨境取证障碍。

2.穷尽国内救济前置布局。诉讼第一步先行启动罗马尼亚国内刑事控告，完整留存检方拖延、拒绝取证、美方拒绝司法协助全部书面记录，消除被告“未用尽国内救济”核心程序抗辩，满足欧人权法院受理硬性门槛。

3.多层法律依据叠加。诉讼架构同时援引《欧洲人权公约》第3、5、8、13条，搭配《禁止酷刑公约》《日内瓦公约》国家责任规则，主张两项核心违法：一是罗马尼亚主动协助CIA酷刑，实体权利受侵害；二是国内无有效追责机制，程序救济落空，实现实体+程序双重诉请。

4.多元第三方协同造势。主动联络大赦国际、国际法学家委员会、欧洲媒体协会提交法庭之友意见书，将个案上升为全欧洲非常规引渡系统性人权危机，放大判例示范价值，属于典型跨国战略性造法诉讼。

5.分层诉讼战略。目标短期：法院确认罗马尼亚国家侵权，判令支付精神损害赔偿金；中长期：确立欧洲公约国家协助酷刑即承担共犯责任司法标准，约束所有欧盟、欧洲委员会成员国不得配合CIA类秘密引渡与黑监狱，建立跨国酷刑受害者追责常态化渠道，填补ICC、美国司法无法追责的空白。

6.审级递进规划。国内刑事调查穷尽后直接向欧洲人权法院提起跨境申诉，申请专门事实听证，倒逼法院调取罗马尼亚涉密机场、检察档案，通过公开庭审曝光黑监狱系统性制度缺陷，不局限于个人赔偿，追求泛欧洲人权规则变革。

回应路径

1.事实全盘否认核心防御。全程否认境内存在CIA秘密监狱，主张过境航班仅常规加油，情报机关完全不知情；援引本国参议院调查报告，称无证据证明官员与美方合作羁押囚犯，试图切断“国家协助酷刑”因果链条。

2.程序抗辩：主张国内救济尚未穷尽罗政府辩称纳什可持续推动国内刑事侦查、上诉至本国最高法院，检方仅进度缓慢而非救济不存在，请求法院直接驳回申诉、不予实体审理。

3.证据保密对抗战术以国家安全、航空信息保密、刑事调查涉密为由，拒绝完整提交机场航行记录、官员问询笔录，仅提供删减版摘要，抬高原告举证难度，阻碍法院查清完整引渡事实。

4.国家主权抗辩。主张境外CIA审讯行为主权归属美国，罗马尼亚仅过境中转，无权干预美方境外羁押政策，公约责任仅适用于本国领土内本国官员主动施暴，不包含协助第三方行为。

5.庭审弱化损害抗辩。庭审中主张纳什涉嫌恐怖犯罪，羁押具有反恐正当目的，隔离管控属于安全必要，弱化酷刑、长期监禁对人身权利的严重侵害程度。

因果启示

1.跨境酷刑受害者可采用“过境缔约国诉讼”战略路径施暴国（美国）司法封闭、无追责渠道时，可对提供中转、场地协助的欧洲缔约国提起欧洲人权法院申诉，开辟独立跨国追责通道，是典型填补司法真空的战略性诉讼模式。

2.国家“不作为/协助”同样构成公约侵权公约第3条禁止酷刑为绝对义务，不区分本国直接施暴或协助第三方实施，国家知情而配合秘密羁押、引渡即需承担责任，大幅拓宽人权诉讼被告范围。

3.政府保密抗辩无法架空人权举证规则大规模系统性人权侵害案件中，法院适用倾斜性举证规则，人权组织、受害者提交基础系统性证据后，举证责任转移至国家，不能以国家安全永久封存关键证据阻碍司法事实查明。

4.穷尽国内救济是此类诉讼必经前置战略步骤战略性跨国人权诉讼必须完整走完本国刑事、司法渠道并留存全部拒办、拖延文书，否则极易被主权国家以程序理由直接驳回，前期取证与国内控告是诉讼成败关键。

5.单一受害者个案可塑造区域通用人权规则本案并非仅实现个人赔偿，通过战略性申诉确立欧洲引渡、情报合作统一人权底线，倒逼各国立法监管跨境秘密羁押，实现个案推动区域制度变革的战略效果。

6.主权、反恐利益不能豁免酷刑协助责任即便以反恐为理由，欧洲公约缔约国亦不得配合第三国实施酷刑类秘密引渡；法院在人权与国家安全权衡中，绝对禁止酷刑条款具备最高优先级，压缩国家借反恐实施人权合作豁免的空间。
