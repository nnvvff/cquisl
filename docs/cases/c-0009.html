原告

Saúl Ananías Luciano Lliuya（秘鲁哈拉斯市农民兼登山导游）

被告

RWE AG（德国最大的能源供应商之一）

案情介绍

RWE公司历史上的温室气体排放是否对秘鲁冰川消融及Palcacocha 湖洪水风险产生了法律意义上的因果关系；以及依据《德国民法典》第1004条，原告是否有权要求被告按其排放比例分摊洪水预防措施的成本 。原告主张RWE公司自1854年以来的累计排放量占全球工业排放的0.47%（后修订为0.38%），导致当地气温升高及冰川融化，使其财产面临由于Palcacocha冰川湖决堤引发的洪水威胁。原告要求被告按比例承担湖区加固和其房屋防灾设施的费用。本案经历了长达10年的审理，包括2022年法院赴秘鲁进行的现场勘验

判决结果

驳回上诉，维持原判。法院虽确认该诉讼在法律逻辑上是可成立的（Conclusive），但认定原告未能证明其财产正面临《德国民法典》第1004条所要求的“具体、迫在眉睫的急性危险”。专家证言显示，未来30年内发生破坏性洪水的概率仅为约1%，属于极低风险，不足以触发预防性防御请求权。

发起路径

1. 法律函告：2012年向被告发送要求函遭拒；
2. 州级诉讼：2015年向埃森地方法院起诉，2016年被以“不具备线性因果关系”为由驳回；
3. 理据突围：2017年向哈姆高院提起上诉，高院发布证据令，首次在法理上认可气候诉讼的法律逻辑可采性；
4. 事实博弈：2022-2024年进行现场证据调查和多次专家听证。

回应路径

1. 管辖权与程序性抗辩：主张诉求不具有确定性（Specificity），且原告缺乏法律利益。
2. 性质否定抗辩：辩称其排放行为是社会可接受且经行政许可的（TEHG框架下合法经营），不构成“违法干扰”。
3. 因果关系抗辩：主张气候系统高度复杂，无法建立排放与单一冰川事件的线性逻辑链条

因果启示

1.科学证据链的预置：被告获胜的关键在于证明了损害概率极低。启示因应方在应对此类诉讼时，应加强对本行业环境影响的权威科学评估，以数据防御“危险迫在眉睫”的指控 。
2.理据反制话语构建：本案显示法院开始采纳“比例原则”来分担责任。中方主体在国际话语中应坚持“共同但有区别的责任”在私法领域的分段化论证，防止“理据越位”导致的系统性风险。
