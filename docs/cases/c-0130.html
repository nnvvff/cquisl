被告

Ian H. Lundin, Alex SchneiterInterveners: Lundin Energy AB

案情介绍

1999–2003年Lundin在苏丹南部区块作业，与巴希尔政府合作。瑞典检方经11年调查，指控高管明知政府以军事清场为油气开发开路，仍提供资金、物流与政治背书，构成对战争罪、反人类罪的帮助与教唆。2021年正式起诉，请求对公司罚款300万瑞典克朗、没收收益约13.92亿克朗。被告与公司均否认指控。

判决结果

仍在审理

发起路径

1.资格策略：利用瑞典普遍管辖+属人管辖，突破苏丹主权与管辖难题；
2. 规范选择：绕开ICC，直接以瑞典国内刑法实施国际法义务，降低起诉门槛；
3. 证据组合：以UN调查报告、NGO实地证据、公司内部文件、前员工证词构建闭合证据链；
4. 话语扩散：捆绑“苏丹暴行—石油利益—企业责任”公共叙事，倒逼司法与政治支持。

回应路径

1.无任何证据证明高管知情或参与军事行动；
2. 当时作业符合UN、EU、瑞典官方“建设性接触”政策；
3. 公司系当地发展正面力量，检方依据不可靠的NGO报告；
4. 追责将严重打击跨国企业投资安全与合规预期。

因果启示
