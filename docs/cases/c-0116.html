原告

Asma Bougnaoui（个人受害者）及人权辩护协会(ADDH)

被告

Micropole SA(法国私营IT咨询公司)

案情介绍

软件工程师Asma Bougnaoui因在派驻客户现场期间拒绝摘除伊斯兰头巾（因客户投诉影响形象）被解雇。原告在人权组织ADDH的支持下起诉，主张该解雇行为构成宗教歧视。法国最高法院随后就如何解释欧盟反歧视指令提请欧盟法院进行初步裁决。核心争议在于：私营企业雇主是否有权以“尊重客户意愿”或“形象中立”为由，禁止员工在客户现场佩戴宗教头巾(hijab)，以及这种限制是否构成第2000/78/EC号指令下的“真实且决定性的职业要求”。

判决结果

原告胜诉。欧盟法院认定：雇主为了照顾客户不愿接受佩戴头巾员工服务的意愿，不属于“真实且决定性的职业要求”。法国最高法院随后在2017年11月22日的判决中确认，在缺乏公司内部统一中立规章的情况下，仅凭单一客户的要求解雇员工构成了直接歧视。

发起路径

1. 组织化起诉：在NGO支持下向劳资法院发起挑战；
2. 理据突围：通过最高法院提请欧盟初步裁决，实现理据在欧盟层面的扩散；
3. 国家执行：利用欧盟法院的权威解释，强制国内法院撤销既有判例倾向。

回应路径

1. 业务必要性抗辩：主张作为咨询公司，必须尊重支付费用的客户对服务形式的特定要求；
2. 中立政策辩护：试图将解雇行为框架化为维护企业在多元化市场中“视觉中立”的合法管理手段。

因果启示

1. 管理权的合规边界：企业不能将“满足客户需求”作为凌驾于员工基本权利之上的理由；
2. 内部规章的程序正义：若需实施中立政策，必须在《员工守则》中制定统一、明确、不具有特定指向性的规则，严禁个案式的、临时性的差别对待。
