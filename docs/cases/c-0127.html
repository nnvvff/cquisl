原告

The Netherlands

案情介绍

申请人因抢劫、盗窃被判监禁及医疗拘禁，2005年《DNA定罪人员检测法》生效后被强制采集口腔拭子。其主张该措施属于事后施加的附加刑罚、侵犯隐私、构成歧视，国内法院驳回后诉至欧洲人权法院。法院认定DNA措施不属于刑罚，对隐私的干预合法且必要，差别对待具有正当理由，最终驳回全部诉求。

判决结果

本案全部主张不予受理，无实体违法认定。

发起路径

1.以受强制采集的被定罪人作为适格申请人；
2. 向国内法院提出异议并穷尽国内救济；
3. 同时援引第7、8、14条三条款提高审查强度；
4. 以“无合理必要性、构成惩罚、差别对待”提出三项核心攻击。

回应路径

1.DNA采集是犯罪预防措施，不属于刑罚，不违反第7条；
2. 有明确国内法依据，为公共安全与打击犯罪所必需，符合第8条；
3. 对重罪已决人员统一适用，差别对待具有客观合理理由。

因果启示

1.刑事领域生物信息强制采集可通过战略诉讼被定性为权利侵犯，需以明确立法、比例原则、严格程序筑牢防御；
2. 预防型强制措施易被挑战为“惩罚”，必须在制度上与刑罚清晰切割；
3. 中国应完善DNA采集、存储、使用、删除的全流程规范，防范被认定为任意或歧视性措施。
