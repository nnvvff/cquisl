案情介绍

申请人 Amanda Kósa 是匈牙利罗姆族少女，居住在社会经济条件较差、罗姆人聚居的隔离社区。当地教会在社区内开办一所教会小学，市政府同步取消原有的免费校车接送服务，改为少量交通补贴。此前本土公益组织已经提起公益诉讼，主张该教会学校与校车政策构成罗姆儿童的种族教育隔离，一审、二审支持该主张，但匈牙利最高法院推翻判决，认为只要是家长自愿择校就不构成非法隔离。Kósa 以自身受教育权、不受歧视权受侵害为由，向欧洲人权法院提交申请，主张匈牙利的教育政策造成罗姆儿童事实上的种族隔离，违反《欧洲人权公约》禁止歧视条款。

判决结果

欧洲人权法院裁定本案不予受理（inadmissible），理由是申请人未能证明自身遭受可识别的、具体的歧视损害，国内公益诉讼已经对相关隔离问题作出终局裁判，申请人的个人诉求与案件事实不满足受理门槛，没有认定匈牙利政府存在公约项下权利侵害。

发起路径

本案属于典型叠加式战略性诉讼。首先由本土民权 NGO 先行在国内提起公益诉讼，推动法院对罗姆教育隔离问题作出裁判、形成公共议题；在国内诉讼败诉、最高法院确立 “自愿择校不构成隔离” 的裁判规则之后，由当事人在公益组织律师支持下，以个人名义穷尽国内救济后向区域人权法院欧洲人权法院提交申请，借助区域人权司法机制挑战本国最高司法确立的规则，目标不在于单纯为个人拿到赔偿，而在于推动区域层面形成少数族裔教育平等的标准，倒逼国内教育立法和反歧视制度修改，联动欧盟层面启动针对匈牙利的违法调查程序。

回应路径

匈牙利政府从三层维度进行抗辩回应。程序层面主张申请人个体损害不充分、国内救济路径已经走完且最高法院判决具有既判力，本案不符合欧洲人权法院受理条件；实体层面援引国内法赋予家长教育选择权，主张教会学校是家长自愿选择，不存在强制隔离，教育质量达标就不构成歧视；制度层面配套立法修订，修改国内平权法与教育法，在保留少数族裔特色教育空间的前提下增设禁止种族隔离的约束条款，同时对接欧盟种族平等指令的要求，用立法调整消解区域司法和欧盟层面的规制压力，以立法方案对冲域外司法审查带来的制度变革要求。

因果启示

该案展现跨境战略性诉讼的典型风险与制度边界，对我国有多重参考意义。一是区分公益诉讼的价值目标，我国公益诉讼以本土公共利益和法律秩序完善为核心，应当警惕域外 NGO 借个人诉讼串联区域人权司法机制，用域外标准干预国内民族教育、义务教育治理；二是重视事实性歧视的识别，教育领域的隔离不一定来自强制划分，补贴、交通配套等公共服务供给的差异同样会造成边缘化效果，可依托现有公益诉讼框架完善平等权保护的事实审查标准；三是把握司法主权边界，战略性诉讼容易出现国内终局裁判被域外司法机制二次评价的情况，需要厘清不同司法体系的效力边界，坚持以国内法作为平等保护的判断基准；四是兼顾选择权和平等权，少数群体特色教育和反隔离不是非此即彼的关系，该案的立法修改思路表明，可在保障家长择校自由的同时，配套公共资源均衡供给、教育质量监管的刚性规则，防范自愿选择演变为事实上的族群隔离。
