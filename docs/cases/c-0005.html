乌尔根达诉荷兰案

Urgenda Foundation v. State of the Netherlands

2015

原告

Urgenda基金会 (代表886名荷兰公民)

被告

荷兰国家政府 (The State of the Netherlands)

案情介绍

Urgenda基金会代表886名公民起诉荷兰政府，认为政府设定的到2020年温室气体减排目标——较1990年水平仅减排14-17%，过低，不足以保护公民免受危险气候变化的威胁。原告要求法院判令政府到2020年底至少实现25%的减排。

判决结果

荷兰最高法院全面驳回了荷兰政府的上诉，维持原判。命令荷兰国家必须在2020年底前，将温室气体排放量在1990年的基础上至少减少25%。

发起路径

自上而下+自下而上
原告直接抽取出国际气候公约（UNFCCC /巴黎协定）中的科学减排目标，将其与具有宪制地位的欧洲人权公约绑定，在民事法院发起侵权诉讼，借司法之手直接给政府制定红线

回应路径

政府辩称，气候政策、减排目标的设定以及国家预算的分配，完全是行政权和立法权的核心领域。法院如果强行命令政府减排，就是在代替政府制定政策，僭越了司法权。
（¶¶ 8.1.1, 8.3.2, 8.3.3）。
荷兰仅占全球排放量的不到0.5%，单独让荷兰严厉减排对全球气候无济于事，且会导致企业外流。（¶5.7.1）

因果启示

1.警惕国际社会将 Urgenda 模式向发展中国家输出，试图用司法手段强行干预他国自主的碳达峰时间表。中国需在国际法域强化“发展权即首要人权”的话语构建。
2. 虽然中国国内不存在法院直接审查行政机关气候减排目标的机制，但本案提示，在制定宏观能源政策时，应确保政策充分科学与严谨，防止在国际交流中被对方以西方判例标准进行“合规降维打击”。
