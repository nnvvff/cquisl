Tarakhel v. Switzerland

原告

Golajan Tarakhel, Maryam Habibi及六名未成年子女

被告

Switzerland

案情介绍

阿富汗家庭经意大利入境欧洲后前往瑞士申请庇护，瑞士依据Dublin规则认定意大利为责任国并决定遣返。申请人主张意大利安置系统存在系统性缺陷，遣返将使其面临不人道待遇。欧洲人权法院大法庭判决：瑞士若未事先获得意大利关于儿童适配安置与家庭团聚的个体保障即遣返，将违反第3条。

判决结果

1.认定在无个体保障前提下遣返将违反《欧洲人权公约》第3条；
2. 第13条诉求不予受理；
3. 判令瑞士支付诉讼费用7000欧元。

发起路径

1.以难民家庭为直接申请人，未成年人作为脆弱群体强化资格正当性；
2. 穷尽瑞士国内救济（联邦移民局、联邦行政法院）；
3. 向欧洲人权法院申请第39条临时措施阻止遣返；
4. 引入UNHCR、欧洲人权机构报告证明意大利系统性缺陷，构建证据链。

回应路径

瑞士政府主张：
1.遣返符合 Dublin 规则，欧盟体系存在互信推定；
2. 意大利有义务提供安置，瑞士无额外审查义务；
3. 已存在联络机制与协调安排，无需个体书面保障。
意大利政府主张：
1. 安置系统持续改善，SPRAR 容量扩大；
2. 带儿童家庭属于脆弱群体，可获得适配安置；
3. 不存在系统性虐待风险。

因果启示

1.区域庇护机制不能免除成员国个体人权审查义务，形式化互信可被司法突破；
2. 涉及弱势人群的跨境处置，必须以书面化、可执行的个体保障作为前置条件；
3. 中国在处理跨境移民、难民、家庭团聚等事项时，应建立规范化的风险评估、保障确认与程序留痕，防范被诉人权违法。
