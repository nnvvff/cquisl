案情介绍

本案为罗姆族女性遭遇疑似非自愿绝育后，因医疗记录复印权引发的人权诉讼。申请人剖腹产术后不孕，怀疑被非法绝育，授权律师调取复印医疗记录以查明原因、准备损害赔偿诉讼，却因斯洛伐克1994年《医疗保健法》的限制性规定，仅获查阅和手写摘录权。国内各级法院及宪法法院均维持该限制，申请人向欧洲人权法院申诉。

判决结果

欧洲人权法院经审理，认定斯洛伐克违反《欧洲人权公约》第8条和第6条第1款，未违反第13条，判令斯洛伐克向申请人支付非物质损害赔偿金及诉讼费。本案确立了医疗记录复印权是《欧洲人权公约》第8条私人与家庭生活权的核心内容，也是第6条诉诸法院权的必要保障。

发起路径

1. 国内行政途径：2002年8-9月，申请人通过授权律师向涉事医院申请复印医疗记录，遭拒。斯洛伐克卫生部明确1994年《医疗保健法》禁止患者授权他人查阅医疗记录

2. 国内民事途径：2003年1月，申请人分两批对涉事医院提起民事诉讼，要求判令医院允许复印医疗记录；国内一审、二审法院均仅支持查阅和手写摘录，驳回复印请求

3. 国内宪法途径：2004年5-6月，申请人向斯洛伐克宪法法院提起宪法申诉，主张国内法院判决违反《欧洲人权公约》第6、8条，宪法法院分别驳回申诉（一批认定未违公约，一批认定申诉不成熟）

4. 国际人权途径：2004年8月30日，申请人向欧洲人权法院提起申请。

回应路径

①实体被告辩称国家已履行了《欧洲人权公约》下的义务，因为法律已允许原告在场查阅并手抄记录，这足以保护其获知权。政府进一步强调，限制复印是为了保护医疗数据中可能涉及的他人隐私和公共卫生利益，属于国家的正当裁量范围

②针对公平审判权的指控，被告抗辩称原告本可以通过国内民事诉讼程序由法官调取证据，是原告自行放弃了这一有效路径，因此不存在证据不平等的问题

因果启示

因其完全处于欧洲人权体系，可供中国借鉴较少。

可能需要国家关注弱势群体/少数民族的人权问题，因为其他国家可能会以此为靶，需要完善“国内行政救济→司法救济→公益诉讼”的多层级权利救济路径，对于制度性的权利侵害，允许公益组织介入代理诉讼，保障弱势群体的人权实现。
