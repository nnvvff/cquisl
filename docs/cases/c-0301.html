巴尔加斯・阿雷科诉巴拉圭案

Vargas Areco v. Paraguay

巴拉圭

原告

GerardoVargas-Areco家属、CEJIL国际人权中心、巴拉圭和平与正义服务组织（SERPAJPY）

被告

巴拉圭

案情介绍

15岁少年1989年违规入伍，因拒绝归队被军官从背后枪击身亡，遗体事前遭受殴打、烫伤等酷刑；军方一审仅轻罚行凶军官，国内普通司法程序拖延十余年，证人拒不出庭、鉴定结论前后矛盾，追责长期停滞。家属穷尽国内救济无果后，联合人权组织向美洲人权委员会申诉，巴拉圭和解谈判消极拖延，案件移送美洲人权法院。因巴拉圭1993年才接受法院管辖权，法院仅审查案发后国家调查、司法救济层面的侵权，无权评判1989年征兵、致死原始行为。

判决结果

法院一致认定巴拉圭侵害受害人家属身心完整权、公正审判权、司法保护权，未履行酷刑调查惩治义务；判令国家公开道歉、支付赔偿金、为家属提供长期心理医疗；全面追责涉案人员；全军常态化开展人权培训；修订未成年人征兵法律对标国际标准。

发起路径

1.完整穷尽国内军事、普通两级司法救济，形成国内救济失灵完整证据链；2.本土+国际人权组织联合代理，协助固定尸检、征兵制度缺陷等关键证据；3.先向区域人权委员会申诉，谈判破裂后移送区域人权法院，以个案推动全国征兵制度变革。

回应路径

1.管辖权抗辩：主张法院对1993年前行为无审理权限；2.事实抗辩：以遗体腐烂为由否认酷刑存在；3.追责抗辩：主张军方已作出刑事处罚，履行国家调查义务；4.和解拖延：假意协商拖延程序推进。

因果启示

1.区域性人权法院可通过个案战略诉讼倒逼成员国修改国内涉未成年人立法，彻底废除儿童兵制度；2.国家司法调查不作为、追责流于形式会被认定系统性违反国际人权公约；3.中国因应参考：境外NGO可借区域人权机制针对我国青少年征兵、军警执法类事件发起跨国诉讼，我国需完善军警人权培训、健全内部监督追责机制，规范涉外人权案件证据对外输出，统一涉外司法答复口径。
