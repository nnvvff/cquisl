案情介绍

Mangold案是欧盟就业与反歧视领域的标志性先例。原告56岁被签订无客观理由的固定期限合同，依据德国法对52岁以上群体的豁免条款。欧洲法院大法庭判决：该年龄豁免构成直接年龄歧视，且不符合比例原则，无法以促进老年就业正当化；即使指令尚未完成转化，禁止年龄歧视已是欧盟一般法律原则，国内法院必须不予适用冲突的国内法。本案开创 “原则先行、横向直接效力、优先排除国内法”的战略诉讼路径

判决结果

1.德国法第14条第3款关于52岁以上固定期限合同的豁免违反欧盟法；
2.禁止年龄歧视属于欧盟一般法律原则，在指令转化期内即具约束力；
3. 国内法院有义务排除与之冲突的国内法。

发起路径

1.资格切入：以受歧视劳动者个人为原告，利用国内劳动诉讼天然资格，撬动欧盟法院preliminary ruling；
2. 规范升级：不局限于指令文本，直接上升到欧盟一般法律原则/基本权利，突破转化期限限制；
3. 效力策略：主张欧盟法直接效力+优先效力，要求国内法院排除国内法，实现跨法域司法强制；
4. 话语包装：将“促进老年就业”重构为“变相标签化与不稳定用工”，占据比例原则与社会保护高地。

回应路径

德国政府主张：年龄门槛旨在促进老年就业，属合法政策目标；措施适当且必要；指令尚未转化无约束力。欧盟委员会支持原告立场，强调禁止年龄歧视的基础性。

因果启示

1.战略诉讼可借区域/国际一般法律原则绕开国内程序与转化期限，实现权利快速落地。
2. 平等原则极易被工具化，“优待/例外”可能被司法认定为歧视，形成反向约束。
3. 中国需警惕国际/区域司法对国内立法权的侵蚀，在参与国际劳工与平权规则时明确转化边界与裁量空间。
4. 应对此类战略诉讼，应强化比例原则说理、政策目标实证化、差别对待正当化依据。
