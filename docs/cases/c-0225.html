原告

多名无名氏未成年儿童（Jane Doe、John Doe，均存在特殊身心障碍）；儿童法定诉讼监护人、儿童父母

被告

夏威夷州教育局（DOE）、夏威夷人类服务部（DHS）

案情介绍

多名Doe未成年子女存在不同程度身心特殊需求，夏威夷人类服务部启动儿童保护程序，家事法院取得儿童监护权，负责保障儿童生活、医疗、教育全部权益。家事法院要求州教育局为特殊儿童出具个性化特殊教育方案（IEP），并调整适龄年级安置；教育局抗辩教育安置属于行政专属职权，家事法院无管辖权、无权强制教育局调整教育安排。教育局认为司法不得干预教育行政事务；儿童代理人与父母主张，未成年人受教育权属于基本人权，家事法院基于 “儿童最大利益原则”，有权统筹儿童全部生存发展权益，行政机关必须配合司法裁判。

判决结果

1. 确认家事法院在儿童监护案件中享有固有、完整管辖权，覆盖未成年人医疗、照料、特殊教育等全部权益事项，不受行政部门职权边界限制；
2. 驳回州教育局上诉，维持下级家事法院裁定，判令教育局限期为涉案特殊需求儿童制定适配个性化教育安置方案；
3. 明确未成年人特殊受教育权具备优先性，行政机关不得以内部行政规则拒绝履行配合儿童权益保护的法定义务

发起路径

1. 夏威夷人类服务部（儿童保护机构）发现儿童监护与照料缺陷，2000 年向家事法院提起儿童保护、临时监护程序；
2. 家事法院作出监护及特殊教育安置指令；
3. 州教育局不服一审裁定，上诉至夏威夷中级上诉法院；
4. 上诉法院部分支持教育局抗辩，儿童代理人、父母向夏威夷最高法院申请调卷复审，案件进入州最高法院审理。

回应路径

1. 教育局抗辩：教育规划、年级安置属于教育行政专属权责，家事法院越权干预行政事务，裁判应予撤销；
2. 儿童方回应：《夏威夷儿童保护法》赋予家事法院全面保障未成年人权益的职权，特殊儿童平等受教育属于法定人权，行政机关负有配合司法保护儿童的强制性义务；
3. 州最高法院采纳儿童方核心主张，否定教育局行政排他性抗辩。

因果启示

1. 人权层面：身心障碍未成年人的平等受教育权、全面照料权是核心未成年人权，司法机关可突破行政分工壁垒，强制行政机关落实儿童权益保障；
2. 司法管辖规则：家事法院儿童监护管辖权是完整管辖权，不限于衣食照料，延伸至教育、医疗等影响儿童成长的全部领域；
3. 权责边界：行政机关的专业职权不能对抗未成年人基本人权保护，当行政安排损害儿童利益时，司法裁判具备优先执行效力。
