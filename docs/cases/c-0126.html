Alleged Breaches of Certain International Obligations in respect of the Occupied Palestinian Territory (Nicaragua v. Germany)

案情介绍

2024年3月1日尼加拉瓜向国际法院起诉德国，指控德国在明知以色列在加沙实施大规模不法行为的情况下，持续军援以色列并切断对UNRWA资助，构成协助灭绝种族、违反国际人道法、支持种族隔离与侵占巴勒斯坦自决权。尼加拉瓜同步申请临时措施，要求德国立即停止军援、恢复对UNRWA供资。2024年4月30日，国际法院以15:1驳回临时措施申请，但重申缔约国防止灭绝种族、尊重国际人道法、不援助不法行为的强行法义务

判决结果

1.ICJ 驳回尼加拉瓜的临时措施请求（15:1）；
2. 法院重申德国负有防止灭绝种族、尊重并确保尊重国际人道法、不援助协助国际不法行为的一般国际法义务；
3. 实体审理仍在进行中。

发起路径

1.资格设计：利用《灭绝种族罪公约》第IX条+任择强制管辖权，以缔约国身份起诉，规避“无直接利害关系”的资格质疑；
2. 规范捆绑：同时诉诸《灭绝种族罪公约》、日内瓦共同第1条、国际人道法强行法、自决权，多重规范强化约束力；
3. 程序策略：同步申请临时措施，制造紧急人道压力，加速司法介入与舆论扩散；
4. 话语联动：串联联合国专家、ICJ既有命令、全球人道危机叙事，形成“司法—舆论—规范”联动。

回应路径

德国主张：
1. 以色列拥有自卫权，德国军助符合国际法；
2. 德国基于历史责任支持以色列具有正当性；
3. 暂停对UNRWA资助基于人员关联指控，程序合法；
4. 尼加拉瓜未满足临时措施的紧迫性、不可弥补损害、表面管辖权要件。

因果启示

1.战略诉讼可突破直接当事国限制，以“普遍性义务/强行法”为由启动国际司法，针对第三方实施政策约束
2. 国际法院虽可驳回临时措施，但会重申法律义务，形成规范先例与话语杀伤，影响后续政策与司法实践
3. 中国需警惕“第三国起诉+临时措施+人道叙事”组合打法，提前构建国际法抗辩体系，明确军贸、援助、对外合作的合规边界与正当性基础。
4. 应对此类诉讼应强化事实透明度、法律定性话语权、国际社会协同立场，防止被工具化定性。
