Sharifi and Others v. Italy & Greece

原告

Sharifi 及其他 34 名阿富汗、苏丹、厄立特里亚难民

被告

Italy；Greece

案情介绍

35名中东与非洲难民经希腊偷渡至意大利港口，被意大利边境警方未做身份核验、未提供法律帮助、未启动庇护程序，直接集体遣返希腊。申请人称希腊收容条件恶劣、无有效庇护渠道，面临遣返战乱国风险。欧洲人权法院仅保留4名申请人诉求，认定意大利、希腊均构成人权侵犯。意大利在港口对难民实施无审查集体驱逐、直接遣返希腊；希腊未提供有效庇护程序与安置条件，导致难民面临被再次遣返阿富汗风险，是否违反第3条、第13条及第4议定书第4条。

判决结果

1.驳回大部分申请人诉求，仅保留4名申请人资格；
2. 希腊违反第13条（结合第3条）；
3. 意大利违反第4议定书第4条（集体驱逐）、第3条、第13条；
4. 希腊赔偿5000欧元诉讼费

发起路径

1.以难民集体作为申请人，依托人权NGO提供法律代理；
2. 穷尽意大利与希腊国内救济后提交ECtHR；
3. 同时起诉两国，构建接力侵权诉讼结构；
4. 申请第39条临时措施阻止遣返，固定证据与诉讼资格。

回应路径

意大利主张：
1. 遣返依据Dublin规则与双边协议，程序合法；
2. 仅1名申请人可被身份核验，其余缺乏入境证据；
3. 责任应由希腊承担。
希腊主张：
1. 已提供权利告知书，申请人未行使救济；
2. 国内资源有限，无法承担全部庇护义务；
3. 多数申请人无法定位，诉求不实。

因果启示

1.边境遣返必须坚持个案审查、程序告知、法律帮助、未成年人特殊保护，杜绝集体驱逐；
2. 国际/区域责任协议不能免除前端人权审查义务，否则构成连带责任；
3. 中国应完善跨境移民程序留痕、救济渠道、未成年人甄别机制，防范被诉程序违法。
