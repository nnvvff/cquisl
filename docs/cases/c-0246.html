案情介绍

案件基础背景（2022年前政策背景）欧盟设立《复苏与复原基金》（RRF），向成员国发放巨额经济复苏资金，配套法治条件性里程碑机制：成员国必须完成司法独立、反腐败等改革节点，欧盟理事会才批准资金拨付。波兰此前司法纪律庭改革严重侵蚀法官独立，欧盟委员会多次启动违规诉讼，欧盟理事会与波兰达成三项司法改革里程碑（F1G/F2G/F3G）作为拨款前提，但改革义务设置宽松、存在大量制度漏洞，未完全修复法官履职保障。

2022年6月：欧盟理事会作出拨款批准决定欧盟理事会通过执行决议，认可波兰复苏计划达标、允许资金发放，仅设置有限司法改革里程碑，未彻底废除侵害法官独立的纪律庭机制，大量波兰法官仍处在被随意惩戒、履职无保障的状态。

2022年8月28日：四大欧洲法官公益组织提起撤销之诉Medel等四家代表全欧法官的非营利司法协会，向欧盟普通法院提起TFEU第263条撤销之诉（公益战略性诉讼），请求撤销理事会拨款决议。原告诉讼核心理由：三项司法里程碑要求不足，决议放任波兰系统性破坏司法独立，直接损害欧盟法官有效司法保护的基本权利，违反《欧盟条约》第19条、《基本权利宪章》第47条。

初审程序对抗（2022—2024）欧盟理事会提交不予受理抗辩，主张原告及所属法官不满足TFEU第263条“直接利害（直接关切）”要件；波兰、匈牙利、欧盟委员会全部介入，支持理事会观点。普通法院将四起关联案件合并、适用快速程序并交由大庭审理。

2024年6月4日：普通法院一审裁定驳回起诉普通法院作出程序裁定，认定案涉理事会决议仅属预算条件类规则，不直接改变法官法律地位；仅给成员国增设积极改革义务，不包含对法官的保护义务，法官不存在直接、个别利害关系，原告无起诉资格，全案不予受理。

2024年8月14日：原告向欧盟法院（CJEU）提起上诉四家法官协会不服初审驳回裁定，正式向上诉庭提交上诉状，提出三项法律抗辩，主张初审对TFEU“直接关切”判例适用完全错误，违反有效司法保护基本权利。2024年10月7日欧盟官方公报公开完整上诉法律理由。

2026年4月16日：欧盟总法律顾问出具支持意见总法律顾问Čapeta出具书面意见，认可上诉方全部核心主张，认定法官协会具备原告资格，要求撤销普通法院裁定、将案件发回初审法院进行实体审理。截至当前欧盟法院尚未作出终审书面判决。

判决结果

1.欧盟普通法院（初审，2024年6月4日裁定）

完全支持欧盟理事会提出的不予受理抗辩，直接驳回四家法官协会全部撤销之诉；

核心理由：案涉欧盟复苏基金决议仅属于预算附带条件规则，调整对象是波兰政府，并未直接创设/变更法官个体的法律地位，不满足《欧盟运行条约》第263条“直接关切（直接利害关系）”原告资格要件；

法院认定仅法案主动施加积极义务才会产生直接利害，公权力不作为（未完善司法保护、改革门槛宽松）不构成对法官的直接法律影响；

诉讼费用由原告四家法官协会自行承担。

2.欧盟法院总法律顾问Čapeta意见（2026年4月16日，非终审判决，但具备极强参考约束力）

建议撤销欧盟普通法院不予受理裁定，将全案发回普通法院进行实体审理；

法律核心观点：（1）对TFEU第263条“直接关切”作目的性、宽泛解释，不能仅看法案文字调整对象，必须评估决议对欧盟基本权利（《宪章》第47条有效司法保护权）的实际损害效果；（2）欧盟理事会明知波兰司法惩戒机制违法，仍设置宽松司法改革里程碑，属于不作为式权利侵害，直接威胁波兰法官独立履职，满足因果联系与直接利害标准；（3）代表全体欧盟法官的行业公益协会，在系统性法治危机案件中应当放宽原告资格认定，不能机械适用Carvalho案的严格限制标准；（4）NordStream2判例确立的“实质法律影响”标准应当适用于本案，普通法院法律解释存在根本性错误。

程序建议：由普通法院重新开庭，实质审查波兰司法里程碑条款是否违反欧盟法治义务。

发起路径

战略诉讼前置目标：以司法审查约束欧盟法治拨款机制四家法官协会属于泛欧公益性职业维权组织，诉讼并非仅维护波兰本地法官，而是战略性欧盟层面公益诉讼：通过法院撤销违法拨款决议，倒逼欧盟收紧所有成员国复苏基金法治条件，确立“司法独立不达标不得发放资金”刚性规则，从欧盟顶层制度限制各国政府打压司法体系的行为。

主体联合布局，强化诉讼代表性整合欧洲多国法官协会共同起诉，覆盖行政、普通、国际法官群体，证明案涉决议损害的是整个欧盟司法职业群体共同利益，提升案件公共重要性，便于法庭之友、人权机构参与支持。

法律依据分层构造，打通程序+实体双重论证程序性依据：援引NordStream2、ECHRKlimaSeniorinnen气候变化案放宽利害关系解释的裁判规则；实体性依据：《欧盟条约》第19条、欧盟基本权利宪章第47条有效司法保护权，主张法治是欧盟核心价值，理事会决议弱化司法保障构成违法。

初审阶段完整举证、对抗不予受理抗辩向法院提交波兰司法纪律庭惩戒案例、欧盟委员会违规诉讼文书、人权机构报告，证明拨款里程碑存在重大缺陷，法官履职风险真实、直接来源于理事会决议；系统反驳理事会“仅属预算条款、不影响法官”的观点。

一审败诉后立即上诉，持续推进战略目标普通法院以程序门槛直接驳回、未进入实体审理，协会迅速提起上诉，将争议上升至欧盟最高司法机关，借上诉程序统一欧盟范围内“法治相关公益诉讼原告资格”裁判标准，形成约束欧盟各机构的司法先例。

整体战略逻辑依托欧盟条约撤销之诉程序，以个案挑战欧盟财政权力的行使边界；利用公益协会集体诉讼优势，弥补单个法官无力对抗欧盟、成员国双重公权力的资源劣势，通过司法判例完善欧盟法治保障体系，属于维护欧盟基础价值的战略性人权公益诉讼。

回应路径

·核心防御战略：以程序资格门槛阻断实体审查理事会不实质回应决议法治缺陷，优先采用程序抗辩，主张原告及所属法官不满足TFEU第263条“直接、个别关切”，直接剥夺法院实体审理权限，避免法院审查复苏资金条件设置是否违法，防止判例限制欧盟财政审批权力。

·限缩决议法律性质，切断与法官权利的因果关联抗辩分层论证：①案涉决议仅为预算拨付附带条件，调整对象是成员国政府，不直接对法官创设权利义务；②“直接关切”仅适用于对当事人产生积极约束的法案，公权力不作为（未完善司法保护）不产生法律影响；③改革里程碑仅约束波兰立法机关，不改变法官现有法律地位，不存在NordStream2案要求的直接法律联系。

·联动成员国共同施压诉讼邀请波兰、匈牙利（均存在司法独立争议）作为介入方共同提交书面意见，同步主张严格限制公益组织原告资格，防止后续各国公民、行业协会批量起诉欧盟财政决议，规避大量同类战略性诉讼。

·援引限制性先例支撑严格资格标准以Carvalho案判例为核心论据，主张行业、公益协会仅在自身专属权益受损时才有起诉权，不能代全体泛欧法官群体主张抽象公共利益，法院不应宽泛解释原告资格规则。

·一审胜诉后上诉阶段持续坚持程序抗辩在欧盟法院上诉程序中维持全部不予受理主张，强调TFEU原告资格条文文本严格，不能因法治、人权理由随意放宽，防止突破欧盟财政决策的司法审查边界。

·整体应诉战略优先运用程序障碍驳回公益诉讼，规避实体层面欧盟拨款政策合法性审查；通过限缩“直接利害”解释、联合成员国、引用保守判例三重手段，削弱民间公益组织挑战欧盟公权力的诉讼渠道，减少战略性公益诉讼对欧盟财政、治理政策的约束。

因果启示

·公权力不作为同样可构成公益诉讼诉因本案打破传统认知：欧盟法案不只是增设义务会产生利害，公权力机构弱化权利保障、放松监管的不作为，若直接损害公民/职业群体基本权利，同样满足起诉的利害关系要件，拓宽战略性公益诉讼适用范围。

·法治与人权类案件应当放宽原告资格解释TFEU等程序条文不能机械字面解读，当案件触及欧盟法治基石、《基本权利宪章》核心司法保护权时，法院需目的性放宽“直接关切”标准，避免严苛程序门槛阻断维护公共利益的战略性诉讼。

·行业公益协会是对抗系统性公权力侵害的核心诉讼主体单个法官资源、诉讼能力薄弱，跨国职业公益协会能够整合群体利益、提起顶层欧盟层面司法审查，是制衡成员国与欧盟双重公权力、推进制度性变革的核心战略诉讼载体。

·行政财政权力（复苏基金拨款）受宪制性法治约束欧盟财政审批权并非绝对自由，附带的法治条件设置必须达到保护基本权利的底线；公益诉讼可对欧盟资金分配权力实施司法制衡，防止欧盟为经济利益妥协司法独立等基础价值。

·程序抗辩是公权力机关压制战略性公益诉讼通用手段欧盟理事会、成员国统一采用“原告资格不予受理”程序策略，回避实体违法审查；此类诉讼中公益组织需同时准备程序、实体双重论证，援引人权判例扩张利害关系解释，破解公权力程序拦截战术。

·跨国公益诉讼具备制度变革战略价值本案并非仅救济波兰法官个体权益，诉讼目标是统一欧盟各国复苏基金法治审查标准，形成约束欧盟所有财政决策的司法规则，属于以个案诉讼推动区域整体人权、法治制度完善的典型战略性公益诉讼。
