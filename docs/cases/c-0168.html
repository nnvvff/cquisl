案情介绍

本案是现代司法史上规模较大、赔偿金额较高的消费者集体环境与卫生侵权诉讼之一。2015年及2019年，魁北克上诉法院作出终审判决，认定包括 JTI-Macdonald 在内的三大烟草企业在过去数十年中刻意隐瞒吸烟致癌的科学事实、误导公众，判令其承担高达150亿加元的巨额赔偿。为避免直接破产清算，JTI-Macdonald 随即依据加拿大《公司债权人安排法》（CCAA）向安大略省法院商事庭申请破产保护，案件由此升级为一场跨区域、跨公私法边界的战略性复杂诉讼。在漫长的复议与破产重组过程中，各省政府、患者集体与烟草企业围绕公司资产如何重组、母公司是否应承担连带责任，以及如何在各省公共医疗系统（追偿治疗吸烟疾病的巨额财政开支）与个人受害者之间分配仅存的数百亿加元烟草资产，展开了激烈的法律博弈。

判决结果

原告与各省政府获得历史性公法胜利（法院终审批准数百亿加元全球卫生信托重组方案）。

 

经过数年的破产庭审拉锯，安大略省高级法院商事庭在近年（2025年）正式签署了里程碑式的终审批准命令（2025 CarswellOnt 14377）。法院裁定：1. 终局清算分配：全面批准了跨越加拿大各省的烟草重组和解协议，总金额高达近 300 亿加元，创下加拿大历史最高纪录；2. 设立公共卫生信托基金：这笔巨额资金被强制划拨用于向患病烟民进行直接不法民事侵权赔偿，并全额注入各省公共医疗国库，以补偿长久以来的卫生系统损失；3. 终结烟草免责时代：剥离并限制了母公司利用跨境结构逃避子公司侵权责任的法律盾牌。该终审裁决标志着跨国烟草巨头试图利用“破产保护”作为永久避风港的战略尝试彻底宣告破灭。

发起路径

长期民事侵权集团诉讼大获全胜 → 逼迫被告进入破产程序，进而将传统‘私法赔偿’升格为对整个行业资产的‘公法重组与社会清算’ → 各省政府依托公权力，以“公共医疗开支追偿债权人”身份强行入局 → 在高级法院商事庭利用破产重组审查权，对跨国母子公司的全球资金链实施司法穿透与长效截流。

回应路径

被告 JTI-Macdonald 及其跨国母公司的防御策略将“公司有限责任”与“经济休克威慑”发挥到了极致。

 

烟草巨头律师极力辩称：1. 魁北克的天价判决金额远超子公司实际净资产，强行执行将导致公司立即破产倒闭，进而造成数万人失业、国家烟草税收断崖式下跌以及非法走私烟草泛滥的宏观社会灾难；2. 依据公司法资本独立原则，海外母公司对加拿大子公司的民事侵权过错不承担连带责任，试图利用破产法中的“中止诉讼”作为无限期拖延赔偿、消耗受害者寿命的政治防线。

因果启示

1. 破解了“赢了官司、拿不到钱”的跨国大企业抗辩死穴：很多战略诉讼最害怕跨国企业利用“子公司宣布破产”来赖账。本案的因果启示在于：破产法庭不是跨国财阀的免罪符，反而可以成为公益诉讼人对整个侵权行业实施‘长治久安式系统性改造’的终极绞肉机。通过将侵权之诉转换为“破产债权人破产重组大战”，成功实现了对跨国企业全球资产的司法长臂绞杀。

 

2. 公私法混合战略的威力巅峰：案件揭示了该战略闭环——前端由个人、NGO通过悲壮的民权侵权诉讼撕开企业的科技与欺骗黑箱，后端由政府公权力以公共财政受损（医疗支出）为由高位接盘、入场收割。这种“民诉发起、公法合围、破产收尾”的复合因果长链，为全球后续针对化石能源巨头（气候洗绿欺诈）、跨国药企（阿片类药物危机）等大型有害工业的战略性司法追责提供了最具震撼力和可复制性的最高实务指南。
