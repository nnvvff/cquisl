State v. Native Village of Nunapitchuk

原告

阿拉斯加州政府（State of Alaska，上诉审原告）

被告

Native Village of Nunapitchuk（努纳皮楚克原住民村及其他原住民联盟，上诉审被告）

案情介绍

本案源于努纳皮楚克等原住民村落此前针对阿拉斯加州政府推行的某些土地、资源分配和环境监管政策提起的公共利益诉讼。

在早期的诉讼中，原住民村落基于公益目的挑战政府行为，但未能获得最终胜诉。根据美国法律传统的“美利坚规则”（American Rule），通常各方自付律师费；但阿拉斯加州此前存在长期的“公益诉讼人豁免传统”（Public Interest Litigant Exception），即出于公益目的起诉政府的诚实原告，即使败诉也无需承担政府方高昂的律师费，以此鼓励民间司法监督。然而，阿拉斯加州立法机关随后通过了第86号众议院法案（HB 86），试图立法彻底取消这一豁免，规定即使是公益诉讼，败诉也必须全额赔偿政府团队的诉讼费。原住民村落联合环保组织发起战略反击，指控该倒退性立法严重侵害了阿拉斯加州宪法赋予公民的“正当法律程序”（Due Process）、“平等保护”（Equal Protection）以及“向政府请愿的权利”（Right to petition），实质上是用金钱壁垒剥夺了底层原住民诉诸司法的机会。

判决结果

原告（州政府）胜诉（阿拉斯加最高法院做出保守裁决，公益诉讼遭受重创）：


2007年4月20日，阿拉斯加州最高法院做出终审判决。法院以4:1的压倒性票数裁定：1. 立法合宪：州立法机关通过 HB 86 法案取消“公益诉讼人费用豁免”的行为完全属于立法机关的宪法职权范围，并不违宪；2. 推翻司法先例：法院认定，宪法中的正当程序和请愿权并不自动保障公民在败诉后免除对造律师费的特权。该判决直接宣告了阿拉斯加州实行了数十年的公益诉讼保护伞彻底破裂，导致未来的原住民及环保NGO面临“一旦告政府失败就倾家荡产”的巨大财务风险。

发起路径

政府通过倒退性费用立法 → 环保与原住民战线组成防御联盟 → 利用个案费用裁决作为切入点，直接将立法技术争端升级为对州宪法顶层人权条款（正当程序、请愿权）的司法审查 → 试图利用最高法院的司法能动性去对抗立法机关的政治清算。

回应路径

州法务部门极力辩称：1. 诉讼费用如何分配属于纯粹的立法政策选择，司法机关必须尊重代议制议会的决定；2. 过去几十年的“公益豁免”导致了大量环保组织和原住民部落针对全省的关键基础设施、石油开采和采矿项目提起“无成本的滥诉”，极大地拖累了州经济民生并虚耗了公共财政。政府成功利用“防止司法瘫痪”的现实主义逻辑说服了多数派法官。

因果启示

寒蝉效应：本案的因果链极为残酷——它证明了反对派完全可以通过“重构费用规则”这一看似不起眼的诉讼程序武器，直接从源头上抽干战略诉讼的财务来源。当“败诉即破产”变成硬性法律时，绝大多数脆弱的原住民社群将彻底失去通过司法对抗强权的勇气。

它启示全球战略诉讼的参与者，不仅要主动用法律去“进攻”不公，更要时刻盯着诉讼程序法（如管辖权、律师费、诉讼保证金）的修改。如果丢失了程序正义的护城河，再漂亮的实体人权理论在法庭上也将由于“告不起”而毫无用武之地。这一案例长期被作为研究美国环境诉讼政策倒退的必读教材。
