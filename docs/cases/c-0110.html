原告

参与者：视觉中国（视觉中国集团股份有限公司）、欧洲南方天文台（ESO）、中国媒体与公众
中国版权协会、国家网信办、北京市互联网法院、图片行业从业者

案情介绍

2019年4月10日，全球首张黑洞照片发布；次日视觉中国在其平台将该照片标注为 “版权所有”，并对使用图片的媒体发送侵权索赔函。事件迅速发酵，公众质疑其对公共领域/开放授权作品的不当版权主张，随后延伸至视觉中国对国旗、国徽、历史照片等公共素材的“版权化”维权行为。国家网信办约谈视觉中国，要求其整改；平台全面暂停服务，最终以公开道歉、下架违规作品、完善版权审核机制收场，成为中国版权行业治理的标志性事件。

判决结果

无司法判决，实质结果：
1. 视觉中国被监管部门责令全面整改，暂停网站运营；
2. 公开道歉，删除黑洞照片等违规版权标注作品；
3. 行业层面强化对公共领域作品、开放授权作品的版权审核规则；
4. 法院后续对同类“版权蟑螂”维权案件采取更审慎态度，降低赔偿金额、严格审查权属。

发起路径

1.商业维权路径：视觉中国先将公共领域/开放授权作品标注为自有版权，再向使用者批量发送律师函/索赔通知，以诉讼为威慑索取授权费；
2. 舆论反击路径：媒体与公众通过社交平台曝光事件，质疑版权主张合法性，形成舆论压力；
3. 监管介入路径：国家网信办、版权管理部门介入约谈，要求平台整改；
4. 行业自律路径：中国版权协会等机构发声，明确公共领域作品保护规则，推动行业规范。

回应路径

视觉中国回应：
1. 黑洞照片由其 “编辑整理”，享有著作权；
2. 维权行为符合《著作权法》，是保护版权的正常商业行为；
3. 后续承认部分版权标注不规范，启动整改。
ESO 回应：
1. 黑洞照片属于CC-BY 4.0 协议，仅需署名，可自由使用；
2. 视觉中国无任何专有版权，其主张无效。
监管部门回应：
1. 约谈视觉中国，要求其健全版权审核机制，不得对公共领域作品标注自有版权；
2. 责令平台暂停服务，全面自查违规内容。

因果启示

1.战略性维权可被舆论与监管反向约束：商业主体以“维权”为营利手段时，易引发公共争议，最终被监管与司法纠正；
2. 公共领域作品是不可触碰的版权红线，任何平台不得将其私权化、主张专有版权；
3. 中国企业在版权运营中需建立严格权属审核机制，避免因“泛版权化”引发合规风险与舆论危机；
4. 司法与监管需对“版权蟑螂”行为建立识别与约束机制，防止版权制度被异化为营利工具，损害公共利益。
