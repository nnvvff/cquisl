案情介绍

英国为军事基地在毛里求斯独立前强行割离查戈斯群岛，驱逐全部原住民。毛里求斯作为小国，在ICJ、UNCLOS仲裁、ITLOS发起多层联动诉讼，主张分割违反UNGA第1514号决议民族自决，英国占领与海洋保护区均非法。ICJ咨询意见明确：毛里求斯非殖民化未合法完成，英国必须尽快结束对查戈斯管理。

判决结果

1.ICJ（2019）：13:1认定分割非法、非殖民化未完成、英国必须尽快结束管辖；
2. UNCLOS仲裁（2015）：英国设立海洋保护区违反海洋法；
3. ITLOS（2021）：采信ICJ意见，否定英国主权主张。

发起路径

1.先打海洋保护区仲裁（切入低敏感、高胜算）；
2. 推动联合国大会请求ICJ咨询意见（政治+司法双重加持）；
3. 借ITLOS案件二次确认ICJ结论，形成司法闭环；
4. 绑定联合国决议、非殖民化规范、全球南方话语联盟。

回应路径

英国主张：分割系自愿协议、主权合法、为地区安全必需；ICJ咨询意见无约束力；拒绝移交主权。

因果启示

1.小国可通过多层级司法连环诉讼以弱胜强；
2. 咨询意见可通过后续案件转化为实质约束力；
3. 民族自决、非殖民化已成为可武器化的战略诉讼核心规范。
