案情介绍

原告麦克唐纳为美国联邦/州监狱在押囚犯，被告Longley系涉案监狱管理人员。原告依据美国《民权法案》42U.S.C.§1983提起联邦民权诉讼，主张监狱管理人员朗利在羁押监管过程中，存在侵犯其宪法赋予的人身安全、医疗保障、免受残酷非常规刑罚等基本人权的行为：
原告称监狱长期拒绝提供必要医疗护理，忽视其慢性病诊疗需求，构成故意漠视囚犯健康；
主张狱警存在不当拘禁、言语及肢体暴力、限制合法申诉渠道等侵权行为；
原告在州地区法院一审败诉后，不服一审判决，于2020年向第五巡回上诉法院提起上诉，案卷编号20-50448。

判决结果

第五巡回上诉法院合议庭经审理，核查监狱管理记录、医疗档案、证人证言后，维持地区法院一审原判，驳回原告麦克唐纳全部上诉请求；
法院认定：被告朗利及监狱管理方的监管行为符合联邦监狱管理规范，不存在《宪法第八修正案》禁止的残酷、非常规惩罚；医疗安排已提供合理基础诊疗，不构成“故意漠视生命健康”；
上诉诉讼相关诉讼费用由上诉人（原告McDonald）自行承担，案件正式结案。

发起路径

1.前置程序：原告在监狱内部走完囚犯申诉行政救济流程，向监狱管理层提交书面投诉，内部救济未达成诉求；
2.一审起诉：2019年原告向美国联邦地区法院（第五巡回辖区内）提交民事诉状，以民权侵权起诉狱官Longley；
3.上诉发起：地区法院作出不利一审判决后，原告委托/自行提交上诉状，2020年完成上诉立案，案卷编号 No.20-50448，由第五巡回上诉法院受理。

回应路径

一审阶段：被告 Longley 联合州司法署出庭答辩，提交监狱医疗日志、监控记录、内部申诉回执等证据，主张监管行为合法合规；
上诉阶段：被告向第五巡回上诉法院提交书面答辩状，抗辩原告无充分证据证明被告存在主观恶意侵权，请求上诉法院维持原判；
庭审回应：口头辩论环节，被告代理律师援引美国联邦囚犯权利类先例，论证监狱管理享有合理自由裁量权。

因果启示

1.囚犯民权诉讼举证门槛高：囚犯依据 §1983 起诉狱政人员，需举证证明官员存在主观故意漠视，仅证明医疗条件一般、监管严苛不足以构成侵权；
2.司法尊重监狱管理裁量权：联邦巡回法院对监狱日常安全、医疗资源分配拥有司法克制立场，不会轻易以事后标准否定狱官现场管理行为；
3.权利救济前置要求：囚犯必须穷尽监狱内部行政申诉流程，未走完内部救济直接起诉的，诉求极易被法院驳回；
4.人权诉讼实操提示：在押人员主张宪法性人权受损时，需完整留存医疗单据、投诉回执、伤情记录等客观证据，否则上诉难以获得法院支持。
