原告

18名捷克籍罗姆人儿童

被告

捷克共和国

案情介绍

在跨国NGO ERRC的策划下，18名被安置在“特殊学校”的罗姆儿童起诉捷克政府。原告指出，特殊学校的课程断绝了日后升入普通中学的可能。捷克政府主张这是基于标准化测试和家长同意，但原告引入美国专家的统计分析，证明当地高达56%的特殊学校名额被罗姆儿童占据，指控这是一种隐蔽的种族隔离。

判决结果

原告逆转胜诉。
2007年，大法庭以13票对4票推翻原判，裁定捷克政府违反了公约。法院确认在反歧视案件中，只要存在可靠的统计数据证明某项政策对特定群体产生了“不成比例的影响”，即可推定存在间接歧视，且不需要证明政府有歧视意图。

发起路径

先是穷尽国内救济。在国内宪法法院败诉后迅速转向。2006年初审遭遇重大挫折时，NGO 将案件推向Grand Chamber，最终依靠压倒性的舆论倒逼法官改变立场。

回应路径

1、parental consent
2、标准客观统一
3、目的善意

因果启示

中国在推行涉及特定群体的公共政策时，必须科学评估数据影响。在程序上保留透明的知情解释过程。
