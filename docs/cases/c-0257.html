案情介绍

两案基础事实分述。（1）Al-Waheed案：2007年2月英军在伊拉克巴士拉搜查抓获Al-Waheed，怀疑其持有爆炸装置，在英军营地拘留六周。彼时英国依据安理会1546号决议作为多国部队承担伊拉克安全维稳任务，当事人起诉拘留无合法依据，违反《欧洲人权公约》第5条人身自由权。（2）SerdarMohammed案：2010年4月英军在阿富汗赫尔曼德抓捕被认定塔利班高级武装人员的SM，初期ISAF规则仅允许96小时临时羁押，英国单独出台内部政策，经部长审批延长拘留至三个半月，直至移交阿富汗国安局NDS。原告主张长期羁押违法，且无独立复核渠道，违反公约第5条。

国内一审起诉阶段（2014）。两名被拘留者分别向英国高等法院依据《1998人权法》提起人权损害赔偿诉讼，主张海外军事拘留违反ECHR第5条人身自由；初审法官分案裁判，Al-Waheed案参照Al-Jedda判例驳回原告诉请，Serdar案认定超期羁押违反公约。英国国防部不服有利原告判决，统一提起上诉。

上诉法院审理（2015）。上诉法院合并两案审理，整体撤销初审对Serdar的有利认定，裁判核心观点：安理会第七章决议授权一切安全必要措施，ISAF96小时时限仅内部行政指引，英国有权自主延长拘留。两原告均在上诉阶段败诉，随后申请飞跃上诉至英国最高法院。

最高法院听证与合议（2016）。最高法院九名法官分两次开庭审理，接纳国际人权机构、红十字相关组织作为法庭之友提交书面意见，集中研讨安理会决议与人权公约效力冲突、非国际性武装冲突拘留规则、战区拘留独立复核三大核心法律难题。

2017年1月17日终审合并宣判。最高法院区分两案作出差异化裁判：Al-Waheed六周拘留实体与程序均合法；Serdar长期拘留实体具备国际法依据，但军方内部复核无独立第三方，违反公约第5(4)条，英国政府需承担赔偿责任。

判决结果

实体认定：依据安理会1546号决议，英军六周安全预防性拘留具备完整国际法合法基础，未违反ECHR第5(1)条。

程序认定：伊拉克占领阶段配套人道审查机制达到公约最低标准，不存在第5(4)条权利侵害。

终局处置：全部驳回原告诉求，无需支付赔偿金。

发起路径

前置证据固化与法律筹备。两名被拘留者释放后长期留存全部拘留文书、问询记录、红十字会见凭证、英军内部羁押政策文件，联合OSJI国际人权律所，整合日内瓦公约、欧洲人权法院先例构建完整论证体系。本案并非单一私人索赔，而是针对英国海外驻军拘留制度的体系性战略性公益诉讼。

分层国内诉讼递进战略。一审阶段同步主张实体非法羁押、程序无独立复核两项诉求，申请法院强制公开英军涉密拘留操作手册；上诉阶段针对上诉法院“安理会决议优先、ISAF规则无约束力”裁判错误展开辩驳；最高法院阶段以推动统一海外驻军司法判例为中长期目标，不止获取个人赔偿。

多重法律依据叠加诉讼架构。诉讼同时援引三重规范体系：《欧洲人权公约》第5条、第三/第四日内瓦国际人道公约、联合国宪章第七章决议解释规则，论证安理会授权不能取消独立司法复核的人权底线义务。

法庭之友协同造势策略。主动联络红十字、欧洲人权公益机构、国际法学者作为法庭之友提交书面意见，拓宽案件公共利益维度，提升判例跨国示范价值。

分层诉讼目标。短期目标：法院认定超期拘留违法，判令政府支付精神与物质损害赔偿金。中长期目标：通过最高法院终审判例，强制英军修改全球海外拘留制度，设立独立于作战部队的羁押复核机构，杜绝无监督长期预防性拘留。

回应路径

核心实体抗辩。

联合国宪章第103条规定安理会决议效力优先于区域人权条约；伊拉克、阿富汗维和决议授权一切维持安全的必要手段，预防性长期羁押属于合法措施，ECHR第5条清单不能机械套用至海外武装冲突场景。

拆分ISAF规则抗辩。

ISAF96小时羁押上限仅多国协调内部操作指引，无强制国际法效力；英国作为主权派兵国，可根据战区恐怖威胁制定独立拘留延长政策，不存在违法基础。

战区客观限制程序抗辩。

阿富汗、伊拉克战时司法体系瘫痪，不具备常规法庭复核条件；英军多层内部审查机制已满足公约反任意拘留的核心目的，可替代独立司法程序。

判例限缩解释策略。

区分Al-Jedda、Hassan案的冲突类型，主张前述判例仅适用于国际战争，阿富汗非国际性内战不适用同等宽松审查标准，限缩欧洲人权判例对英国海外行动约束。

多级程序拖延战术。

一审提交涉密军事文件申请密封审理；一审败诉后立刻集体上诉，消耗原告资金与时间成本；最高法院庭审侧重陈述战区反恐实操困难，引导法院优先权衡国家安全利益。

整体应诉战略。

以安理会维和授权、武装冲突特殊情势双重理由作为抗辩盾牌，维护英军海外自主羁押权限，拒绝增设独立外部复核机制，避免判例限制未来海外反恐、维和拘留权力。

因果启示

战略性诉讼可分层实现实体、程序双重制度矫正。

即便原告无法推翻军方实体拘留权限，仍可依托程序人权诉请倒逼军事制度改革，建立中立复核机制，从流程层面遏制任意长期羁押，实现人权诉讼中长期制度变革目标。

安理会维和决议无法豁免《欧洲人权公约》核心程序义务。

最高法院划定清晰法律边界：安理会授权仅放宽拘留实体事由，独立司法复核属于不可克减的基础人权底线，各国海外驻军不得仅依靠军方内部自查。

国际人道法与人权公约并行适用，冲突时兼顾底线权利。

境外武装冲突案件需同步适用两套国际法体系，不能以战争特殊情势完全架空人身自由程序性保障，法院采用“特别法适配、核心人权保留”平衡规则。

多国部队内部规范无强制国际法约束力。

北约、ISAF统一军事流程仅用于各国行动协调，主权国家可结合本地安全风险调整羁押时限，但调整后的政策仍必须遵守本国缔结人权条约。

国际人权公益组织是对抗海外军事权力关键主体。

单独被拘留个人证据、法律资源不足，依靠OSJI等国际人权机构整合材料、法庭之友论证，才有能力启动顶层战略性诉讼，推动全国性司法判例出台。

该类战略性诉讼具备双重约束效力。

个案层面可使受害者获得损害赔偿；制度层面倒逼一国修改全球驻军拘留规则，对所有参与联合国、北约维和行动的缔约国形成重要司法参考范本。
