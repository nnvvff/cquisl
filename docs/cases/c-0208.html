登顿诉布朗斯米尔开发公司案

Denton v. Browns Mill Dev. Co.

国家/地区
美国

国内法院

已决
细分领域

案卷编号
S01G0515
诉状提交时间

2002

原告

Denton等(土地所有者/社区居民)

被告

Browns Mill Development Co., Inc. 等(地产开发商)

案情介绍

该案源于房地产开发商起诉阻挠开发的居民及土地所有者“非法入侵”（trespass）。佐治亚州的反策略性滥讼（Anti-SLAPP）法规规定，对于涉及公民行使言论自由与请愿权利的行为，原告若提起诉讼，必须在诉状中通过“宣誓核实（verified pleading）”的方式证明其诉请并非恶意滥讼。原告开发商在起诉非法入侵时，未能提交该项核实材料。地方法院因其程序性缺陷驳回了起诉。双方围绕该特定“非法入侵”行为是否属于反滥讼法规的涵盖范围以及程序性验证的必要性产生争议。

判决结果

佐治亚州最高法院裁定维持原判。法院指出，虽然并非所有非法入侵行为均属于反滥讼法规的保护范畴，但本案中，原告开发商在未依法履行必要的“宣誓核实”程序情况下起诉，导致其诉讼请求因程序性不合规而被驳回。法院强调了程序法规则在防御恶意诉讼中的刚性约束力。

发起路径

1.策略性诉讼封口：开发商利用“非法入侵”这一常规私法侵权诉由，试图通过民事诉讼的压力，迫使社区居民停止针对土地开发的抗议活动。
2.民事程序合规化施压：利用诉讼带来的高额律师费和程序拖延，实现对公共参与者的“寒蝉效应”。

回应路径

1.反滥讼程序防御(Anti-SLAPP motion)：被告方精准捕捉原告在诉讼程序中的疏漏，即未依法进行“宣誓核实”，并据此向法庭提出程序性驳回动议。
2.程序正当性合规要求：强调Anti-SLAPP法规的程序性要件（如宣誓核实）不仅是形式要求，更是防止滥诉的刚性屏障。

因果启示

1.共性启示：在应对开发商发起的SLAPP诉讼时，程序合规性审查是防御的第一道防线。即便核心争议未直接落入反滥讼法的保护实体范围，原告若在程序要件（如验证、宣誓）上存在瑕疵，即可构成有效的程序性卡口。
2.个性启示：明确了“宣誓核实”在反滥讼法中的实质法律效力。该案证明，针对公共参与行为的民事起诉，其程序性门槛严于一般民事诉讼，原告方必须确保立案时的每一个程序环节均符合法定合规要求，否则将面临诉权被直接剥夺的风险。
3.中国涉外法治指引：中资出海企业在境外面临类似土地开发或基建抗议时，应高度重视当地反滥讼法规（Anti-SLAPP）的合规性。在提起相关反击诉讼时，务必对诉状的程序要件进行严格审核，防止因简单的程序性疏漏（如缺乏宣誓验证）导致诉讼请求在立案阶段被直接驳回，并需对境外NGO可能利用此类程序条款反向围猎中资项目保持高度警惕。
