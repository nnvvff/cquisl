Data Protection Commissioner v. Facebook Ireland and Maximillian Schrems

原告

爱尔兰数据保护专员（DPC，形式原告）、Maximillian Schrems（马克斯·施雷姆斯，实质战略诉讼发起人/附带被告）

被告

Facebook Ireland Ltd（脸书爱尔兰公司）

案情介绍

本案是数字化时代最典型的“以四两拨千斤”的公益隐私战略诉讼。

奥地利法学生兼活动家施雷姆斯主张，脸书（Facebook）将欧洲用户的个人数据从爱尔兰子公司跨国传输到美国母公司。由于美国《外国情报监视法》（FISA）第702条以及第12333号行政命令赋予了美国情报机构（如NSA）对跨国电子数据进行大规模、无差别监控的绝对权力，且欧洲公民在美国法下缺乏实质的司法救济权，因此美国无法为欧洲公民提供“实质等同”的数据保护。施雷姆斯向爱尔兰DPC提起申诉，挑战两大数据传输杠杆：1. 欧美顶层政治条约《欧盟-美国隐私盾协议》；2. 企业通用数据传输工具《标准合同条款》（SCCs）。爱尔兰地方法院随后将此系列核心宪制问题移送至欧盟最高司法机关。

判决结果

原告获得全面历史性胜诉（欧盟法院废除欧美顶层跨境数据条约）。


2020年7月16日，欧盟法院（CJEU）做出大国数字地缘政治大地震式的终审判决（C-311/18）：
1.废除隐私盾：正式宣告欧盟委员会关于欧美《隐私盾协议》具备充分保护效力的决定彻底无效（Invalid），理由是美国国内法的窃听权优先于人权，严重违反了《欧盟基本权利宪章》；
2. 重塑SCC：虽然原则上保留了《标准合同条款》（SCCs）的效力，但增加极其严苛的附加义务——判定企业不能闭眼签字，如果目的地国（如美国）的法律侵犯隐私，企业和监管机构必须主动终止数据传输。该判决直接导致欧美跨境数据流动陷入长达数年的法律真空。

发起路径

核心法学家组建专业NGO（NOYB） → 锁定全球科技巨头（Facebook）作为靶子 → 向基层监管机构（爱尔兰DPC）提起具体申诉 → 巧妙利用欧洲“提请先行裁决”（Preliminary Reference）机制，将具体个案的技术争端跨层级引爆为欧盟法院对欧美顶层外交条约的违宪审查 → 击穿多边地缘框架。

回应路径

被告Facebook及美国政府（作为利害关系方深度介入）的防御策略高度聚焦于“数字商业秩序”与“地缘国家安全”。

他们辩称：1. 限制数据流动将彻底瘫痪大西洋两岸数万亿美元的数字贸易和云计算生态，给全球经济带来不可估量的灾难；2. 美国的海外情报情报搜集属于至高无上的国家安全事务，且美国已设立了“隐私盾监察员”等救济渠道，司法不应过度介入国际政治防线。但这些经济与政治施压最终在欧盟法院强硬的人权防御立场面前全面溃败。

因果启示

它向世界证明，一个没有国家背景的公益法学者，通过精准撕扯数字公法条文，完全可以依法废除两大超级地缘经济体（美、欧）之间最高层级的政治协定。战略诉讼在数字隐私领域的威力不亚于传统的关税壁垒。

该案的因果链直接逼迫跨国企业（如微软、谷歌、亚马逊）全面调整全球云架构，大量推行“欧洲数据留在大陆”的本地化存储合规策略，并迫使美国总统在后续不得不通过签署全新的行政命令来约束自身情报机关的权力。它证明了战略诉讼可以作为重塑国际商业秩序与跨国规则的终极杠杆。
