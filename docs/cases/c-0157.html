案情介绍

本案是中东欧地区首批直接追究国家气候不作为民事过错的开山之作。

 

原告M.G.在波兰经营着一家历史悠久的家族农场。由于波兰政府长期依赖煤炭能源、迟迟不肯制定明确的碳中和时间表，导致波兰近年来频繁爆发极端的季节性干旱和毁灭性冰雹，原告的农作物连年绝收，地下水源彻底枯竭，生存面临灭顶之灾。

 

原告在国际顶尖法律NGO“ClientEarth”的深度支持下依据《波兰民法典》第417条关于“国家机关行使公权力造成损害的民事侵权责任”条款提起公诉。原告主张，波兰政府在减排上的重大怠惰构成了民事违法过错，直接侵害了其在波兰宪法及《欧洲人权公约》下受保护的“财产权”、“私人和家庭生活受到尊重的权利”，请求法院裁定政府不作为侵权，并强制责令波兰政府承诺在2030年前将温室气体排放量减少至少61%，并在2043年前全面实现碳中和。

判决结果

未决（成功打破不予受理的僵局，进入上诉及国际法理倒逼阶段）。

 

一审管辖权拉锯：波兰地方民事法院在审理早期表现出极大的保守性，倾向于采纳政府的抗辩，认为国家宏观能源政策和国际气候承诺属于“主权行政裁量”，普通民事法官无法在私法侵权之诉中直接向国库签发具体的减排强制令。

 

最新进展（2024–2026年）：原告团队并未放弃，利用波兰政府2024年以来亲欧派内阁上台后的政治转机，迅速提起上诉。同时，由于欧洲人权法院（ECtHR）在2024年历史性裁定“欧洲国家有义务保护公民免受气候危机侵犯人权”，原告将该顶级国际判例打包作为核心证据强行注入波兰上诉法院，目前案件正处于民事二审的激烈实体证据交换与法庭辩论中。

发起路径

精选在中东欧煤炭转型中深受其害的民生典型（农场主） → 引入ClientEarth顶级的国际气候科学与因果关系量化证据 → 绕开死板的行政诉讼，激活《波兰民法典》第417条的“公权力不法侵权” → 将抽象的国际《巴黎协定》指标拆解为保护个体人身与财产的私法注意义务 → 利用欧洲区域顶级人权判例形成“外部法理围剿”推进上诉。

回应路径

波兰政府的辩护逻辑死守“煤炭依赖型国情抗辩”与“私法排除适用”。

 

政府法务部门（General Counsel to the Republic of Poland）极力辩称：1. 国家的减排速度必须与波兰高度依赖煤炭的重工业转型能力和能源安全相匹配，属于绝对的国家地缘政治与宏观经济主权；2. 《民法典》第417条旨在纠正具体的、直接的违法行政行为（如非法强拆），全球变暖是多国排放的累积结果，不具备民法意义上可量化的“直接因果关系”，普通民事法庭如果支持原告，将彻底瘫痪国库。

因果启示

本案是全球气候战略诉讼在“高阻力地缘环境（依赖传统化石能源国家）”破局的极佳范本。

 

在波兰这种极度保守、长期在欧盟内部阻挠激进环保立法的国家，通过行政或立法途径推动减排几乎寸步难行。本案的因果启示在于，通过民法典中“国库侵权”的口子，将宏观的政治议题成功包装为“国家少减排，就是抢夺农民私有财产”的私法逻辑，逼迫法院不得不开庭审理，从而在法律层面上强行撕开了高阻力国家的气候缺口。

 

此案展示了国际NGO的高超操盘技巧——ClientEarth并不自己作为原告（容易被攻击缺乏诉讼利益），而是作为幕后军师，为最接地气的本地个体公民提供大国诉讼级别的法理与资金弹药。这种“国际法理内化为本土民事侵权”的链条，为全球其他面临重工业转型压力的发展中国家开展战略诉讼提供了极其深刻的实务指引。
