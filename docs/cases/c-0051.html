案情介绍

2007年12月肯尼亚大选结果公布后，全国爆发大规模选后暴力事件，期间多名女性和男性遭受强奸、轮奸、强迫割礼等性与性别暴力（SGBV）。2013年2月，4个人权组织联合8名SGBV受害者向肯尼亚高等法院提起公共利益诉讼，指控肯尼亚总检察长、检察长、国家警察总监等6名被告未履行法定职责：未预判并防范选后暴力中的 SGBV风险、未对相关犯罪开展有效调查和起诉、未向受害者提供医疗救助、赔偿等有效救济，违反了肯尼亚宪法及《禁止酷刑公约》《非洲人权和人民权利宪章》等国际义务。案件经多年审理，肯尼亚高等法院于2020年12月10日作出判决

判决结果

1.宣告被告未对选后暴力中的SGBV相关犯罪进行独立有效调查和起诉，违反了肯尼亚国家对5、6、8、9号申请人的生命权、禁止酷刑权及人身安全权负有的积极义务；
2. 宣告5、6、8、9号申请人在2007-2008年选后暴力期间，其生命权、禁止酷刑权、人身安全权、法律保护权、平等与不受歧视权及救济权因肯尼亚政府未履行保护义务而遭受侵犯；
3. 判令肯尼亚政府向5、6、8、9号申请人每人支付400万肯尼亚先令的一般损害赔偿金；
4.判令5、6、8、9 号申请人的诉讼费用由1号和4号被告承担，其他各方自行承担各自诉讼费用；
5. 驳回申请人的其他诉讼请求（包括对7、10、11、12号申请人的权利侵害认定、惩罚性赔偿等）

发起路径

1.起诉：2013年2月，4个人权组织联合8名SGBV受害者向肯尼亚高等法院提起公共利益诉讼（application），主张政府相关部门未履行SGBV防治与救济义务，请求法院作出宣告性判决、判令赔偿并责令政府采取补救措施；
2. 被告反对：Respondents提交答辩意见（observe opinion），主张申请人缺乏诉讼资格、案件构成既判力、政府已履行合理职责、部分受害者未报案导致无法调查，请求驳回起诉；
3. 法院审理：法院审查双方提交的证据（包括受害者证言、专家意见、国际组织报告等）及法律主张，围绕诉讼资格、既判力、权利侵害认定、国家责任等核心问题审理后，于2020年12月作出判决。

回应路径

1.诉讼资格抗辩：主张废止的肯尼亚宪法仅赋予被拘留者权利救济的诉讼资格，2010年宪法关于公共利益诉讼的条款无溯及力，申请人无权就2007-2008年的行为提起诉讼；
2. 既判力抗辩：声称类似选后暴力相关诉求已在其他案件中审理，本案构成重复诉讼，应适用既判力原则驳回；
3. 国家责任抗辩：主张国家对公民的保护义务是一般性义务，而非针对特定个人的专属义务，选后暴力规模突然且庞大，警方与人口比例失衡，政府已尽合理努力维护秩序，无法做到全方位保护；
4. 证据与程序抗辩：辩称部分受害者未向警方报案，导致无法开展调查起诉，申请人提交的证据存在传闻证据，缺乏医疗报告等实质性证据支持权利侵害主张；
5. 救济义务抗辩：主张政府已通过公共医院提供医疗服务、通过相关机构提供心理辅导，未剥夺受害者的救济途径，不存在救济义务违反。

因果启示

1.反制"诉讼资格挑战"：若面临类似追溯性权利主张的诉讼资格质疑，可举证相关法律条款的适用范围，明确程序权利的溯及力限制，强调国家责任的认定需结合行为发生时的法律框架；
2. 反制"国家责任扩大化"：针对性别暴力等事件的国家责任主张，可举证已履行合理预防与保护义务（如部署警力、提供医疗服务），事件规模超出合理预判，且部分受害者未履行报案等配合义务，国家不应承担无限责任；
3. 强化证据与程序合规：在类似案件中，提前留存已履行职责的证据（如警力部署记录、医疗服务记录），主张受害者需对权利侵害、因果关系承担举证责任，反驳缺乏实质性证据的主张；
4. 完善救济机制举证：举证已建立多元化的受害者救济渠道（如医疗救助、心理辅导、报案渠道），不存在救济义务的违反，同时强调救济的实现需受害者主动配合，避免因个别案例否定整体机制的有效性。
