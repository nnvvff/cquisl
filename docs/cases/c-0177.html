案情介绍

本案涉及加拿大刑法中“性同意（consent）”范围的重大争议。

2017年，被告Ross Kirkpatrick通过网络认识一名女性，双方决定发生性关系。双方此前明确约定，性行为必须使用安全套。第一次性交过程中，被告使用了安全套；但在第二次性交过程中，被告未使用安全套，而被害人在行为结束后才发现这一事实。

被害人随后报警，被告被控性侵（sexual assault）。

案件核心争议在于：

当一方明确表示只有在使用安全套的条件下才同意发生性行为，而另一方违反该条件进行性交时，是否属于没有取得有效同意的性侵？

被告主张：

被害人已经同意发生性交；
未使用安全套不影响其对性交行为本身的同意；
如有欺骗，也只能属于《加拿大刑法》第265条关于“欺诈导致同意无效”的问题。

检方则认为：

性行为中的具体方式和条件属于同意的重要组成部分；
被害人同意的是“使用安全套的性交”，而不是“未使用安全套的性交”；
因此不存在对相关性行为的自愿同意。

判决结果

判决结果 加拿大最高法院最终驳回Kirkpatrick上诉，确认案件应重新审理。

多数意见由Martin法官撰写，认为安全套使用可以属于“sexual activity in question”（相关性行为）的组成部分。法院指出，刑法中的同意不是对抽象性交行为的一般同意，而是针对具体性行为的主动、自愿同意。

如果当事人明确表示“我同意使用安全套的性交，但不同意不使用安全套的性交。”那么两者属于不同的性活动。因此，对使用安全套性交的同意，并不自动意味着对未使用安全套性交的同意。性自主权要求尊重个人对于身体风险的自主决定。

法院强调，安全套不仅涉及避孕，也涉及性传播疾病风险；身体安全；生育选择；个人身体自主权。因此，违反安全套使用条件，会直接侵犯个人决定身体如何被使用的权利。

无需证明额外欺诈因素，法院认为，本案不必完全依赖传统“欺诈导致同意无效”的分析路径，因为关键问题不是被害人被骗后撤销同意，而是被害人从未同意这种具体形式的性行为。

发起路径

被告路径：

涉嫌性侵 → 初审法院审理 → 获判无罪 → 检方向不列颠哥伦比亚省上诉法院提出上诉 → 上诉法院推翻无罪判决并要求重新审判 → 被告向加拿大最高法院申请上诉。

案件进入最高法院后，核心转化为：

加拿大刑法中的“同意”是否涵盖性交过程中的具体条件，以及违反该条件是否构成性侵。

回应路径

检方及支持方主要采取以下回应：

1. 强调“具体同意”原则
检方认为，现代性犯罪法已经从传统的“是否同意性交”转向：是否同意该次、该方式、该条件下的具体性行为。因此，不能将同意简单理解为“同意发生性关系”。

2. 维护身体自主权
法院采用更加重视个人自主性的解释方式：个人有权决定是否发生性行为；与谁发生；以何种方式发生；在什么安全条件下发生。任何违反这些条件的行为，都可能超越同意范围。

3. 限制传统刑法解释

法院拒绝采取过度形式主义解释，即不能认为“只要同意性交，就意味着同意所有性交方式。”这种解释会削弱性自主权保护。

因果启示

R v Kirkpatrick案的重要意义在于，其进一步发展了加拿大性侵同意理论：

第一，本案确立了“条件性同意（conditional consent）”原则。
性同意不是一次性的概括授权，而是针对具体行为和具体条件的持续授权。

第二，本案强化了现代刑法中对于身体自主权的保护。
法院承认，安全套使用等行为条件不仅属于个人偏好，而可能属于决定是否同意的重要因素。

第三，本案对于全球范围内“stealthing”（未经同意摘除或拒绝使用安全套）问题具有示范意义。

其法律逻辑可以扩展至避孕条件；性健康风险控制；身体接触范围限制；性行为方式约定。

案件体现了现代刑法从传统“行为是否发生”转向“行为是否获得具体、真实、自主同意”的趋势。
