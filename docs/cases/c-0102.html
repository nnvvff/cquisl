郭玉珍损害商业信誉罪案（“奶农郭玉珍实名举报伊利案”）

呼和浩特市中级人民法院（二审）；呼和浩特市回民区人民法院（一审）

原告

郭玉珍（山西省应县海军奶牛养殖专业合作社经营者）;呼和浩特市回民区人民检察院

被告

内蒙古伊利实业集团股份有限公司

案情介绍

2018年，山西奶农郭玉珍因伊利公司违约停止收奶遭受巨额损失。在常规索赔无果后，郭玉珍采取了“舆论扩散施压”的策略，雇佣网络推手撰写《内蒙伊利公司如此欺压奶农谁来保护弱势奶农利益诉求》等文章，在70余家网站广泛散布，并以此要挟伊利支付805万余元的赔偿清单。面对这种“扩散逼宫”，伊利公司未进行民事回应，而是直接向属地公安刑事报案。最终，法院认定郭玉珍利用网络随意散布不实内容，破坏企业商誉，以“损害商业信誉罪”判处其有期徒刑一年。

判决结果

二审法院既驳回了检方“敲诈勒索”的抗诉（因缺乏非法占有故意），也驳回了郭玉珍的无罪上诉（确有散布不实内容损害商誉），维持有期徒刑一年的原判。郭在刑满释放后表示将继续申诉。

发起路径

1. 产生基础民事纠纷（停收原奶争议）。
2. 维权方雇佣推手跨平台扩散（70多家网站发文）。
3. 维权方向企业亮出价码（交出805万索赔清单，否则继续上访发文）。
4. 企业不妥协，直接向属地公安报案，案件从民事瞬间跃升为刑事公诉程序。

回应路径

程序内抗辩。郭玉珍拒不认罪，一审被判“损害商业信誉罪”后坚持上诉要求无罪；检方同时提起抗诉要求以更重的“敲诈勒索罪”严惩。

因果启示

在国际层面，西方常用高额的民事名誉侵权诉讼（SLAPP）来应对揭黑者或弱势群体的指控；而本案反映了中国实体在反制“恶意发声”时，具备一种特有的、且更具破坏力的路径——“刑事化反制（Criminal SLAPP）”。
它证明了中国企业在面对外部舆论施压与战略性诉求时，拥有极其强硬的“底线思维”，倾向于寻找对方的“越界点”，从而动用最严厉的强制工具一剑封喉。这种国内磨练出的强硬防御基因，或许会隐性影响中国实体未来在国际舞台上因应战略性诉讼的策略偏好。
