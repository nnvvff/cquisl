Vedanta Resources PLC and another v. Lungowe and others

原告

Vedanta Resources PLC (英国母公司) & Konkola Copper Mines plc (KCM, 赞比亚子公司)

被告

Dominic Liswaniso Lungowe 以及其他 1,825 名赞比亚当地村民

案情介绍

赞比亚Chingola地区的1826名村民指控Nchanga铜矿排放有毒物质污染了当地水道，损害了他们的健康和农业活动。村民在英国起诉了该铜矿的实际运营者（赞比亚子公司KCM）以及其英国母公司（Vedanta）。核心争议在于英国法院是否拥有管辖权，而这取决于英国母公司是否对赞比亚村民负有普通法上的“注意义务”(common law duty of care)。

判决结果

英国最高法院驳回了被告的管辖权异议上诉，裁定英国法院具有管辖权，案件可以在英国继续审理。法院认为，基于Vedanta对其子公司运营的干预和控制程度，村民对Vedanta存在“真正可审理的问题”（real issue to be tried），且如果案件在赞比亚审理，原告将面临无法获得实质性司法救济（substantial justice）的风险。
(判决书 ¶42, 87, 88-101)

发起路径

原告采用了经典的 “锚定被告”策略 (Anchor defendant strategy)。
首先在英国起诉英国母公司Vedanta，证明对其指控并非虚假。在英国法院确立初步管辖后，再通过程序规则将海外的实际致害方 (KCM) 作为“必要或适当当事人”追加进诉讼中。

回应路径

被告通过提出管辖权异议和不方便法院原则进行对抗。被告辩称赞比亚才是本案“适当的审理法院”，并指控原告起诉母公司纯粹是为了牵连子公司的“滥用程序”行为。

因果启示

企业应落实尽职调查，确保母公司制定的政策在子公司层面得到有效执行。如果母公司仅宣称自己负责监督却无实际作为，反而会被诉“违反注意义务”。
