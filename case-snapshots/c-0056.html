案情介绍

艾琳・格鲁特布姆及其他899名受访者（含510名儿童）原居住于西开普省开普敦大都会区瓦拉塞德内的非正式棚户区，居住条件恶劣（无水电、卫生设施，房屋拥挤且临近主干道），部分人已等待保障性住房分配长达7年。1998年9月，受访者因无法忍受现有处境，非法占用了一块预留用于廉价住房建设的私人土地（命名为“新勒斯特”）。1999年5月，在土地所有者申请下，受访者被强制驱逐，房屋被推土机推平、财物遭焚毁，最终被迫在瓦拉塞德内运动场搭建临时棚屋避难，冬季暴雨中处境艰难。受访者向开普敦高等法院起诉，主张南非政府违反《南非宪法》第26条（住房权）和第28(1)(c)条（儿童庇护权），请求判令政府提供临时住房。高等法院支持受访者诉求，南非各级政府（国家、省、大都会区、市）不服上诉至南非宪法法院。2000年10月4日，宪法法院作出终审判决。

判决结果

1. 部分支持上诉，撤销高等法院基于《宪法》第28(1)(c)条作出的命令；

2. 确认《宪法》第26(2)条要求国家在可用资源范围内，制定并实施全面协调的计划，逐步实现住房权；

3.宣告国家住房计划存在缺陷，未为“无土地、无住所、居住条件恶劣或处于危机状态”的群体提供合理救济，不符合第26(2)条要求；

4. 指令国家住房计划需纳入类似“加速管理土地安置计划”的合理措施，为上述群体提供救济；

5. 无关于诉讼费用的命令。

发起路径

1.起诉：1999年5月，受访者向开普敦高等法院提起诉讼（application），主张政府违反《宪法》第26条和第28(1)(c)条，请求判令提供临时住房；

2. 被告反对：Appellants（南非各级政府）提交答辩意见（observe opinion），辩称已制定全国性住房计划并投入大量资源，住房权的“逐步实现”不意味着即时满足个体诉求，受访者非法占地被驱逐符合法律规定；

3. 法院审理：高等法院判决支持受访者；政府上诉至宪法法院，宪法法院于2000年5月开庭审理，结合种族隔离历史背景、住房短缺现状及宪法原则，于2000年10月作出终审判决。

回应路径

1.权利性质抗辩：主张《宪法》第26条规定的是“获得适足住房的权利”而非“直接获得住房的权利”，国家义务是“逐步实现”而非即时满足，需结合可用资源合理推进；

2. 政策合规抗辩：举证已制定全国统一的住房政策框架，通过立法明确各级政府职责，投入大量资金建设保障性住房，1994-1997年间已建成或在建住房超36万套，补贴发放超63万份，已履行合理措施义务；

3. 儿童权利抗辩：认为《宪法》第28(1)(c)条规定的儿童庇护权，首要责任主体是父母而非国家，仅在儿童缺乏家庭照顾时国家才需提供替代照顾，受访者中的儿童仍由父母照料，国家无直接提供庇护的义务；

4. 非法占地抗辩：主张受访者非法占用私人土地，违反土地管理相关法律，驱逐程序合法，政府无义务为非法行为产生的后果承担额外责任。

因果启示

1.反制“绝对权利主张”：若面临社会经济权利的即时实现诉求，可举证权利的“逐步实现”属性，强调需结合资源能力制定合理计划，而非承担无条件的即时满足义务；

2. 反制“政策缺陷指控”：针对政策未覆盖特定群体的指控，可举证政策的整体性、系统性成效（如覆盖范围、资源投入、长期目标），同时主动完善政策漏洞，将极端困难群体纳入救济范围，体现政策的合理性与灵活性；

3. 反制“责任主体混淆”：在涉及儿童等特殊群体权利时，明确首要责任主体（如父母、家庭）与国家的补充责任边界，避免国家被过度追责；

4. 强化程序与实质并重：在处理非法占地、强制驱逐等问题时，既要保障法律程序的合法性，也要注重人道主义原则，避免因执行方式不当引发权利侵害指控，确保行政行为与宪法价值一致。
