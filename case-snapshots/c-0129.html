案情介绍

本案是美国生殖权利领域里程碑式案件。联邦最高法院以6:3推翻维持近50年的 Roe 判例，不再承认宪法第十四修正案“自由权”包含堕胎选择权，不再适用“胎儿存活性”分界标准，改用1868年第十四修正案通过时的历史传统作为权利认定依据。判决允许各州自定堕胎规则，大量州随即全面禁止堕胎。异议意见指出，判决动摇身体自主权、隐私、婚姻平权等一系列实体性正当程序权利，破坏遵循先例原则，是基于法官立场而非法律逻辑的政治裁判。密西西比州禁止妊娠 15 周后堕胎的法律是否合宪；美国宪法是否保护堕胎权；Roe v. Wade (1973) 与 Planned Parenthood v. Casey (1992) 判例是否应当被推翻。最高法院最终以历史传统标准否定堕胎权的宪法根基，推翻前例，将堕胎管制权力交还各州。本案是影响性诉讼 / 战略性诉讼的标志性反面样本，揭示司法激进裁判对社会运动与权利格局的颠覆性后果

判决结果

1. 宪法未保护堕胎权；2. 推翻Roe v. Wade与Planned Parenthood v. Casey；3. 堕胎管制属于各州立法权限。

发起路径

1.资格设计：由州卫生官员作为原告发起，以州立法权合宪性为切入点，规避原告资格争议；

2. 规范策略：放弃中间路径，直接以推翻Roe为目标，绑定最高法院保守派席位优势；

3. 先例攻击：以遵循先例例外为武器，主张Roe“推理薄弱、造成社会混乱、不可行”，制造推翻合法性；

4. 证据与话语：以19世纪堕胎管制历史为依据，将堕胎权与宪法割裂，占据道德与民主话语高地。

回应路径

1.异议意见（Breyer/Sotomayor/Kagan）：判决粗暴破坏遵循先例，仅因法院成员结构改变而推翻旧例；堕胎权属于身体自主与性别平等核心，与避孕、同性婚姻、婚姻平权共享法理根基；

2. 各州回应：红州迅速出台全面堕胎禁令，蓝州强化堕胎权保护；

3. 社会回应：大规模民权抗议，企业、学界、国际组织普遍批评；

4. 学界回应：批评判决开启权利倒退周期，威胁LGBTQ+权利、避孕权、跨种族婚姻权等一系列既判权利

因果启示

1.战略性诉讼不仅能创设权利，也能爆破权利；司法轨道的控制权是战略诉讼胜负核心。

2.过度激进的司法裁判会中断渐进式社会变革，引发剧烈社会反弹，破坏法治公信力。

3.中国需警惕“权利先例爆破”与宪法解释武器化，构建稳定的权利体系与裁判说理框架，防止外部势力借类似路径进行规则颠覆与人权话语围堵。

4. 进步权利的巩固必须依赖立法+司法+社会共识多重支撑，单一依赖司法先例极易被翻盘。
