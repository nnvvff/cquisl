案情介绍

1999年12月，俄罗斯联邦军队在车臣格罗兹尼开展军事行动以控制该地区。2000年1月，申请人马戈梅德・艾哈迈托维奇・哈什耶夫的4名亲属（兄弟、姐妹及两名侄子）与申请人罗扎・阿里博芙娜・阿卡耶娃的兄弟在格罗兹尼市斯塔罗普罗米斯洛夫斯基区遭俄罗斯联邦军人杀害，尸体存在枪伤、刺伤、骨折等暴力痕迹。申请人于2000年分别向欧洲人权法院提起申请，主张亲属的死亡系联邦军人所为，俄罗斯当局未对相关死亡事件开展有效调查，违反《欧洲人权公约》第2、3、13条。案件经合并审理，欧洲人权法院于2005年2月24日作出终审判决。

判决结果

1.驳回俄罗斯政府关于申请人未用尽国内救济的初步异议（6票赞成、1票反对）；

2. 一致认定俄罗斯违反《公约》第2条（生命权），具体包括：

(1) 申请人亲属遭联邦军人杀害，国家需承担责任；

(2) 当局未对死亡事件开展充分有效的调查；

3. 一致认定俄罗斯未违反《公约》第3条（禁止酷刑）的实体规定，但违反该条的程序性要求（未对酷刑指控开展有效调查）；

4. 以5票赞成、2票反对认定俄罗斯违反《公约》第13条（有效救济权）；

5. 判令俄罗斯向第一名申请人支付15,000欧元非金钱损害赔偿金，向第二名申请人支付20,000欧元非金钱损害赔偿金，另支付10,907欧元诉讼费用及开支，上述款项需在判决生效后3个月内以俄罗斯卢布支付，逾期未付需支付相应利息。

发起路径

1.起诉：2000年4-5月，两名申请人分别向欧洲人权法院提起申请（application），主张亲属遭俄罗斯联邦军人杀害，当局未履行调查与救济义务，请求法院认定俄罗斯违反《欧洲人权公约》并判令赔偿；

2. 被告反对：Respondent（俄罗斯政府）提交答辩意见（observe opinion），以申请人未用尽国内救济为由请求法院宣告申请不可受理，同时辩称亲属死亡circumstances不明，相关调查已依法开展；

3. 法院审理：法院于2002年12月宣告申请可受理，2004年10月举行公开听证会，审查双方提交的证据（包括调查文件、证人证言、法医报告等）及法律主张，于2005年2月作出终审判决。

回应路径

1.国内救济用尽抗辩：主张俄罗斯法律提供了民事与刑事两种救济途径，申请人可向最高法院或居住地法院提起诉讼，且第一名申请人已通过国内法院获得损害赔偿，证明国内救济有效，申请人未穷尽相关途径；

2. 死亡原因抗辩：提出多种替代解释，声称申请人亲属可能遭车臣武装分子报复、抢劫犯杀害，或因参与武装抵抗被军方击毙，否认联邦军人系凶手；

3. 调查有效性抗辩：主张当局已根据国内法开展刑事调查，核查了申请人的主张，但因缺乏目击证人等原因未能锁定具体责任人，调查程序符合法律规定；

4. 酷刑指控抗辩：援引尸体检查报告，主张报告仅记载枪伤，无证据证明申请人亲属生前遭受酷刑，申请人的酷刑指控缺乏实质依据。

因果启示

1.反制“国内救济用尽”指控：若面临类似抗辩，需举证国内救济在实践中存在不可行性（如程序繁琐、缺乏实质救济效果），或案件涉及核心人权侵害，国际司法救济具有必要性，避免被以“未穷尽国内途径”驳回诉求；

2. 反制“行为主体不明”抗辩：在涉及国家机关或军人行为的案件中，可举证事件发生时相关区域处于国家权力控制之下，仅国家机关具备实施该行为的能力，结合证人证言、现场证据等形成完整证据链，推定国家责任；

3. 反制“调查有效”主张：针对被诉方声称已开展调查的抗辩，可举证调查存在拖延、未收集关键证据、未询问核心证人、缺乏独立性等缺陷，证明调查未达到“有效”标准；

4. 强化程序性权利主张：在涉及酷刑、生命权侵害的案件中，不仅要主张实体权利受损，更要聚焦程序性义务的违反（如未开展有效调查、未提供有效救济），通过双重权利主张提升诉求的说服力。
