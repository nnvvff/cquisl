案情介绍

2009年5月6日，11名索马里国民和13名厄立特里亚国民乘坐三艘船只从利比亚出发，试图前往意大利海岸，在兰佩杜萨岛以南35海里的马耳他搜救区内被意大利税务警察和海岸警卫队的船只拦截。意大利当局将他们转移到意大利军舰上，没收了其个人证件，未告知真实目的地且未进行身份核实，随后将他们遣返至利比亚。申请人称在利比亚面临酷刑和不人道待遇风险，且可能被任意遣返回原籍国遭受迫害，遂于2009年5月26日向欧洲人权法院提起申请，主张意大利的行为违反《欧洲人权公约》相关规定。案件经审理后，欧洲人权法院大法庭于201年2月23日作出终审判决。

判决结果

欧洲人权法院大法庭作出如下判决：1. 剔除两名已去世申请人的案件；2. 认定申请人处于意大利的管辖权范围内；3. 裁定意大利违反《公约》第3条，因其将申请人转移至利比亚的行为，使申请人面临在利比亚遭受不人道待遇及被任意遣返至索马里和厄立特里亚的真实风险；4. 裁定意大利违反《公约》第四议定书第4条，该转移行为构成集体驱逐外国人；5. 裁定意大利违反《公约》第13条（与第3条、第四议定书第4条结合适用），未为申请人提供有效的救济途径；6.判令意大利向每位申请人支付15,000欧元非金钱损害赔偿及1,575.74欧元的诉讼费用和开支，并支付逾期利息。

发起路径

1.起诉：2009年5月26日，申请人向欧洲人权法院提起申请（application），主张意大利的拦截和遣返行为违反《欧洲人权公约》及相关议定书条款，要求确认违法并获得赔偿；

2.被告反对：意大利政府作为Respondent提交意见（observe opinion），辩称拦截遣返是合法的搜救和移民管控行为，依据与利比亚的双边协议开展，否认公约条款的域外适用，质疑申请人的诉讼主张；

3. 法院审理：法院于2011年6月22日举行公开听证会，审查双方提交的证据和意见，同时考虑第三方干预者的陈述，最终于2012年2月23日作出终审判决，支持申请人的核心诉求。

回应路径

1.管辖权抗辩：主张拦截和转移行为发生在公海，意大利未对申请人行使 "绝对和专属控制"，否认《公约》条款的域外适用；

2.行为合法性抗辩：称相关操作是基于与利比亚的双边协议，属于合法的移民管控和海上搜救措施，符合《联合国海洋法公约》等国际法律规定；

3.风险不存在抗辩：主张利比亚是安全的接收国，已批准多项国际人权公约，且联合国难民署在利比亚设有办事处，申请人不会面临迫害风险；

4. 救济途径抗辩：称申请人可通过意大利国内刑事法院寻求救济，主张国内救济途径有效，申请人未穷尽相关救济；

5. 集体驱逐不成立抗辩：认为涉案措施是拒绝入境而非"驱逐"，第四议定书第4条不适用于公海拦截行为。

因果启示

1.反制"管辖权规避"：若面临类似被诉方以"行为发生在域外"为由规避责任的情况，可聚焦"有效控制"标准，举证对方对相关人员或区域行使了实际控制，主张国际人权公约的域外适用效力；

2.反制"合法行为抗辩"：针对被诉方以"合法政策/协议"为由的抗辩，可深入举证该政策或协议的执行存在人权侵害风险，且未履行必要的审查义务，违反不驱回等核心国际法原则；

3.反制"救济途径充足"主张：若被诉方声称存在国内救济途径，可举证该途径缺乏实效性（如无暂停执行机制、程序繁琐、无法保障基本权利），主张其未提供符合国际标准的有效救济；

4. 强化风险举证：在涉及跨国转移的案件中，需提前收集接收国人权状况的权威证据（如国际组织报告、司法判例），明确证明转移行为将导致的具体人权风险，夯实主张的事实基础。
